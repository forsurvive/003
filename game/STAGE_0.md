## 1. 범위 요약 (SD-19 §5.3)

프롤로그 MQ-P1~P4 + MQ-101(추적조 해법 5가지), 장소 4곳(S-07, S-07 비상 탈출구, 관악산 전망바위, 봉천 계단마을), 맵 16장,
인물 약 25명, 적 5종, 서류 UI 5종, 대화·퀘스트·변수, 화술 판정, 카르마, 봉천 호감도, 수배도 1단계, 등록 카드 0~3, 핍-보이 3탭,
저장 전 종류, 터치 HUD, 데이터 파이프라인 v1.

## 3. 진행 기록

(단계마다 끝날 때 적는다.)

### 0-1 이야기 핵심 (2026-10-13)
- **식 언어** `core/story/expr.gd`: 조건(`V_ACT >= 2 and AFF_YH >= 50`, `V_REACTOR in [2, 3, 4]`, `not K_CODE`, `has("I-x")`)과
  효과(`V_DOL = 3; karma(50); quest("MQ-P1", 30)`). 같은 문법의 파이썬 판 `tools/pipeline/story_expr.py`가 빌드 때 구문·변수·함수를
  검사하고, 대조 사례 25개(`tests/data/expr_cases.json`)를 두 쪽에서 계산해 값이 같은지 본다.
- **변수 저장소** `var_store.gd`: 선언(타입·기본값)된 키만 읽고 쓴다. 저장은 기본값과 다른 값만(정렬, 왕복 바이트 동일).
- **퀘스트** `quest_log.gd`: `<키>_STAGE·_RESULT·_SKIP`(SD-03a §4.4), 단계는 오르기만, 건너뛰면 SKIP, 알림 사건.
- **화술** `speech.gd`: SD-10 §3.5.8 식(카리스마 항·대상 호감 + 세력 호감 ×0.25·책임감 × 카르마), 0.9 이상 확정, 표시 반올림,
  판정 고정(씨앗 + 판정 ID), 초기 스킬값 표, I~V 요구치.
- **이야기 상태** `story_state.gd`: 변수·퀘스트·주인공 서류(S.P.E.C.I.A.L.·태그·스킬)·소지품·실패한 판정. 함수 karma·aff·quest·result·
  give·take·has·caps·xp·wanted·stat·skill. 저장 왕복.
- **텍스트 제어 코드** `core/text/text_fmt.gd`: `\P \V[] \N[] \I[] \L[] \K \J[] \T[] \C[] \W[] \.` (SD-12 §14.1), 천 단위 쉼표.
- **대화 실행기** `dialogue_runner.gd`: 대사·효과·조건 이동·선택지·연출 명령. 선택지 태그(화술 % 계산, 능력치·스킬 미달 숨김, 캡·물건
  부족 회색, 증거, 카르마, 관리자 인증), 실패한 판정 다시 안 나옴, 판정 XP, 대화 기록 400줄.
- **원고 변환기** `tools/pipeline/script_compile.py`: SD-19 §9.3 원고 형식 → `data/dialogue/*.json`. 자동 검사: 토큰 문법·변수 선언·
  조사 짝, 화자 ID(SD-07b), 표정 키, 라벨, 식, 글자 수(대사 160/320자, 선택지 80자), 금칙 명칭(SD-18 §2.3·§11.7에서 155개 추출,
  두 글자 한글은 어절 경계), 진영 결정 질문 문형, 화술 선택지의 실패 이동, 태그 2개 상한. 일부러 틀린 원고로 15종 모두 걸리는 것 확인.
- **파이프라인 v1(이야기)** `extract_story.py`: 변수 151(SD-03a §4.2·4.3·4.6·4.7, SD-06 §3.2 호감도 시작값, SD-18 이름 변수),
  퀘스트 16(SD-03a 단계 표), 인물 ID 796(SD-07b). 한 줄 실행 `tools/build_data.sh`.
- **첫 원고**: `script/prologue/MQ-P1.txt`(의무실 출생신고·돌잔치 주민 6명·길 막는 아기·돌잡이 6갈래) 장면 9, 대사 26줄 — 리드 검수 대기.
