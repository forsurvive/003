> 기준 문서: [SD-19 개발 로드맵](../docs/seoul-fallout/19_dev-roadmap.md) §5.2·§6·§10.4.
> 엔진: **Godot 4.7.2-stable**(T 착수 때 최신 안정판, `tools/setup_godot.sh`가 sha256으로 고정 설치). 렌더러 Compatibility.

## 1. 실행 방법

| 목적 | 명령 |
|---|---|
| Godot 설치(세션마다) | `tools/setup_godot.sh` |
| 단위 시험 | `tools/test_game.sh` (스크립트 오류도 실패로 센다) |
| 데이터·그래픽 다시 만들기 | `python3 tools/pipeline/extract.py` → `python3 tools/pipeline/art_import.py` → `python3 tools/map/bake_test_area.py` |
| 시험 구역 실행 | `godot --path game` (SD-11 §2.3: WASD 이동, CapsLock 걷기 토글, Shift 질주, Space 회피 구르기, Q 집중 사격, 마우스 왼쪽 사격·오른쪽 정조준, R 재장전, 1·2 무기, Alt+1~6 장비 교체 시험, F5/F9 빠른 저장·불러오기) |
| 녹화·회귀 시나리오 | `-- --autopilot`(정문 출입), `-- --combat`(교전), `-- --passive`(반격 없음), `-- --save-roundtrip`, `-- --soak`(통합 시험), `-- --touch` / `--touch-demo`(터치) |
| 벤치 | `godot --path game res://scenes/bench/bench.tscn` → `user://bench_report.json` |
| 내보내기 | `godot --headless --path game --export-release "Windows Desktop" ../export/windows/seoul_fallout_t.exe` (Linux, Web 같음) |

## 5. 측정하며 고친 것

- 경로 격자 재구축 17ms → 1.2~2.0ms(타일마다 함수 호출 대신 붙은 청크의 deco 배열을 직접 훑음).
- AI 최대 13.9ms → 1.0ms(점프 탐색 + 전술 갱신 엇갈림).
- 서서 조준하는 적이 바라보는 방향을 갱신하지 않아 시야각에서 표적을 놓치던 문제(교전 중에는 표적을 계속 본다).
- 정문 통로 1타일 → 3타일(반지름 0.3t 충돌체가 정렬 없이 지나가게).

## 6. G-T까지 남은 일

1. **실기기 측정**: Windows(D-P2), Android(D-A2), iOS(D-I2). Android는 네트워크 허용(dl.google.com) 뒤 이 환경에서 빌드 가능, iOS는 macOS 환경 필요(H-10).
2. 페이퍼돌 남은 층(몸 장비·손 무기·등 장비, 방향별 그리기 순서), 구르기·질주 원화(단계 0).
3. 근접 파워 공격, 무장 해제(무기 부위 명중), 패드 질주 토글.
4. AI 스파이크 원인 분석(프레임당 경로 질의 분산), 경로 64×64 대응.
5. H-11 화면비 비교 화면 2종, 16px 폰트 확인, 디버그 콘솔, 자동 저장(일시 정지 알림).
6. ★1× 판독 시험(G-S 이월 과제).
