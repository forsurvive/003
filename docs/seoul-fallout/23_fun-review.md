## 1. 페르소나 — '지나가는 사람'

이름 대신 별명으로 부른다. **지나가는 사람**(줄여 '지나').

| 항목 | 내용 |
|---|---|
| 경력 | Fallout 3 · New Vegas · 4, Skyrim, 젤다 BotW · TotK, Outer Wilds, 디스코 엘리시움, 쯔꾸르 RPG 수십 편. 오픈월드에서 메인보다 옆길에 시간을 더 쓴다 |
| 습관 ① 마커 끔 | 퀘스트 마커를 끄거나 무시한다. 연기 · 불빛 · 소리 · 이상한 지형을 보고 방향을 정한다 |
| 습관 ② 받고 미룸 | 퀘스트를 받으면 일단 미룬다. 기록에 열 개쯤 쌓아 두고 지나가다 생각나면 한다 |
| 습관 ③ 실험 | "이 사람 쏘면 어떻게 되지?", "이걸 먼저 하면?", "저 지붕에 올라가면?"을 실제로 해 본다. 주요 NPC도 쏜다 |
| 습관 ④ 이상한 길 | 정문 대신 하수구 · 옥상 · 뒷담. 대화로 풀 수 있으면 대화로, 아니면 몰래, 그래도 안 되면 총 |
| 싫어하는 것 | 빈 들판을 오래 걷기 · 같은 대사 반복 · "다음에 와" 식 시간 때우기 · 설명이 긴 NPC · 정답이 하나뿐인 퍼즐 · 내가 한 일을 세계가 모르는 척 · 이유 없이 막힌 문 · 왕복 심부름 |
| 좋아하는 것 | 우연히 찾은 쪽지가 다른 곳을 가리킬 때 · 내가 한 일을 낯선 사람이 아는 척할 때 · 같은 일을 다른 방법으로 풀 수 있을 때 · 실패해도 이야기가 이어질 때 · 작은 농담 · 지형이 이야기를 할 때(무너진 다리, 막힌 터널의 낙서) |
| 플레이 길이 | PC에서 한 번에 2~3시간, 휴대폰으로 출퇴근 20분. 20분 안에 뭔가 하나는 끝내고 싶다 |
| 말투 | 솔직하다. "이거 지루해", "오 이건 좋다", "이 사람 왜 이걸 말해 줘?" |

## 2. 재미 질문 F1~F12

검수 때 해당하는 질문만 답한다(모두 답할 필요 없음). 점수 1(지루함)~5(꼭 해 보고 싶음).

| # | 질문 | 무엇을 보나 |
|---|---|---|
| F1 | **첫 1분 훅** — 이 장소·퀘스트에 처음 닿은 1분 안에 '뭐지?'가 있나 | 흔적(소리 · 연기 · 시체 · 이상한 소품)이 먼저 보이나, 설명보다 장면이 먼저인가 |
| F2 | **발견의 보상** — 마커 없이 찾아온 사람에게 따로 주는 것이 있나 | 숨긴 상자 · 쪽지 사슬 · 대사 판 · 지름길 |
| F3 | **해법의 폭** — 말 · 몰래 · 총 · 꼼수(환경 · 물건) 중 몇 가지가 실제로 되나 | 하나만 되면 2점 이하 |
| F4 | **이상한 행동에 대한 응답** — NPC를 쏘거나, 순서를 뒤집거나, 받고 안 하면 세계가 '그럴 듯하게' 반응하나 | 막히거나 모르는 척하면 감점(SD-20과 겹침 — 정합은 SD-20, 재미는 여기) |
| F5 | **세계가 기억하나** — 결과가 호칭 · 값 · 바크 · 풍경 · 방송 중 어디에 남나 | 결과마다 최소 하나(P12) |
| F6 | **반복·빈 곳** — 같은 대사 · 같은 무리 · 빈 길이 연달아 나오나 | SD-22 반복 피하기 · 소장소 밀도 |
| F7 | **동선 피로** — 왕복 심부름 · 기다리기만 하는 시간이 있나 | 기다림엔 할 거리, 왕복엔 지름길 · 새 장면 |
| F8 | **말의 맛** — 대사가 짧고 인물이 살아 있나, 설명을 늘어놓지 않나 | 40자 · 말씨 · 농담 한 줄 |
| F9 | **실패도 이야기** — 지거나 놓쳐도 다음이 재미있나 | 실패 판 · 만료 결과가 '벌'이 아니라 '다른 이야기'인가 |
| F10 | **선택의 무게** — 고른 것이 눈에 보이게 무언가를 잃게 하나 | 둘 다 가질 수 있으면 무게 없음 |
| F11 | **20분 단위** — 휴대폰 20분 안에 끝나는 한 덩어리가 있나 | 저장 지점 · 짧은 사슬 |
| F12 | **'해 보고 싶다'** — 이 요소에서 지나가 스스로 해 보고 싶은 엉뚱한 짓 하나 | 그 짓이 실제로 되면 가점, 막히면 이유가 그럴듯한가 |

## 3. 절차

1. **계획 때**: 새 퀘스트 · 장소 · 시스템의 설계안(또는 SD 원문 절)을 페르소나에게 보여 주고 F1~F12 중 해당 질문으로 점수와 "가장 아쉬운 셋 · 해 보고 싶은 짓 하나"를 받는다.
2. **구현 뒤**: 원고 · 진행기 · 벤치 스크린샷을 보여 주고 다시 묻는다. 계획 때 지적이 풀렸나 본다.
3. **반영**: 지적마다 ① 고침 ② 정본과 충돌 — 구현 정합 메모로 제안 ③ 이월(이유) 중 하나로 처리하고 `game/STAGE_*.md` 해당 단계 기록에 **'재미 검수'** 줄로 남긴다.
4. **운용 방법**: 에이전트 `.claude/agents/openworld-player.md`(같은 페르소나 · 같은 질문표)를 쓴다. 에이전트를 쓸 수 없으면 이 문서의 질문표로 직접 답한다. 페르소나는 칭찬보다 지적을 우선한다 — "다 좋다"는 답은 다시 묻는다.
5. **정합과의 관계**: SD-20 점검(모순 없나)과 SD-20 §10 교차 점검(퀘스트끼리)을 먼저 통과시키고, 재미 검수는 그 뒤에 한다. 재미를 위해 정합을 깨는 제안은 받지 않는다(정합을 지키며 재미있게 다시 설계한다).
