# SQ-S03 「곰팡이의 근원」 구현 설계안 (1-11d, 계획 단계 — 재미 검수 · 교차 점검용)

원문: SD-04a §4.3(L514~). 관련: SD-09a L-R01-02 · 08 · 10, SD-03a MQ-P4 곰팡이병, SQ-S02 B(우회 관로가 S03을 단계 10으로 연다 — 지금은 받을 장면이 없다).

## 고정 지침과의 정합
- **볼트 출구는 정문 방폭문 하나**: 원문의 'S-07 비상 탈출구(L-R01-02)'는 바깥 계곡 쪽 배수 출구로만 쓴다. 갱도 E-01은 바깥 끝(바위로 위장한 녹슨 원형 철문 — 물이 나오는 구멍) → 중간 수문 → **볼트 쪽 용접 창살**(2215년 용접 자국, 물만 지나간다)에서 끝난다. 볼트 안으로 들어갈 수 없다.
- 볼트 안 인물(방금례 · 하로운 · 송새봄 · 조안민)은 1막에 만나지 않는다. 1막의 볼트 접점은 정문 인터컴뿐(방금례). 4막 판(송새봄 · 하로운 · 조안민 · 볼트 농장 회복 연출)은 **이월**(MQ-401 · SQ-S07) — 변수만 남긴다(SQR_S03).

## 발동(셋 다 같은 단계 10으로 — 먼저 오는 것 하나, 나머지는 '이미 앎' 판)
1. MQ-101 끝난 3일 뒤 06시: 조수안이 배수지 탱크 벽을 보여 달라며 게시판 쪽지('배수지 탱크 벽 — 검은 것. 아는 사람?') · 조수안 대화.
2. SQ-S02 B(우회 관로) 직후: 지금처럼 단계 10 — 조수안이 '관에서 물이 오는데 냄새가 이상해' 한 줄로 받는다(지금 빈 약속을 채움).
3. 탱크 벽 곰팡이를 먼저 조사(쪽지 · 조수안 없이 우연히) → 단계 10.
4. K-08 정비공 측정지를 먼저 읽음 → 퀘스트가 열리면 단계 50까지 '이미 앎'으로 건너뛰는 판(P2).

## 단계 · 장소
- 10 탱크 벽(X-BS) 곰팡이 조사.
- 20 볼트 정문 인터컴(X-S07 기존 '인터컴 잡음' 자리)에서 방금례가 '수경 농장 곰팡이병 보고(LR-27)' 요지를 읽어 준다 — 호출 단추를 세 번 누르면 받는다(1막 봉쇄 중이라 처음엔 잡음). 또는 K-08 측정지(“농장 2동 것과 같다”)를 읽으면 20을 건너뛴다.
- 30 조사 지점 3곳 중 2곳: ① 배수지 유입관 거름망(X-BS) ② K-08 옛 관로 이음부 곁 검은 줄무늬 ③ L-R01-02 갱도 출구 물길(E-01 바깥 끝 — 미끈한 막). 핍-보이 '살펴보기'(조사 단추).
- 40 K-08 암거 진입(곰팡이 군락 천장 — 손전등 반경, 이미 cv 정전 필터). 첫 진입: 시궁쥐 CR-095 ×4~6 + **왕쥐 CR-097 ×1**(새 크리처 — 시궁쥐보다 크고 흉터 · 꼬리 묶음, 무리를 부른다).
- 50 정비공 유해의 측정지 M-302(지금은 쪽지 K-08-WATER만 준다 → 물건 M-302도 준다. 이미 읽었으면 그대로).
- 60 측정지 + E-01 중간 수문 조사('수문 아래 물이 미끈하다 — 위에서 내려온다').
- 70 해법 하나 · 100 조수안 보고.

## 해법(원문 수치 그대로)
- A 소각: 화염병 W-057 ×3 · 화염방사기 W-030 · 즉석(부탄가스 M-023 ×2 + 점화 장치 M-038, [폭발물 25]) — 천장 군락 소품이 그을음으로 바뀐다. 봉천 물 정상. 7일 밤 옴 너구리(CR-136, 1-T2에서 이미 있음) RE +30%(따뜻한 암거를 잃음). 카르마 0 · BC +6.
- B 약품: [과학 50](측정지 있으면 25) + 세제 M-021 ×2 + 시너 M-022 ×1 → 수질 측정 상자의 분무기. 카르마 +25 · BC +6.
- C 원인 차단: E-01 중간 수문 [수리 25] 또는 [힘 6]으로 닫고 + 인터컴으로 방금례에게 측정지 수치를 읽어 준다([화술·쉬움], 측정지면 자동). 군락이 14일에 걸쳐 마른다(K-08 천장 소품이 날마다 옅어짐). 카르마 +100 · BC +8. 볼트 농장 회복은 4막(SQR_S03 = 3) 이월.
- D 필터만: 배수지 [수리 25] + 강판 M-013 ×1 → 30일 정상, 그 뒤 재발해 단계 40으로(쪽지 · 조수안 '또 검은 게'). BC +3.
- A·B 뒤 C를 하면 C로 덮어쓴다(카르마는 C 몫만 더).
- 정비공 인식표(2214, 계승명 '정영수'): 인터컴으로 알리면 카르마 +25(납골 벽 이름은 4막 이월).
- 보상: 300 XP · 조수안 100캡 + '봉천 정수 필터'(배수지 물 Rad 0, 상시 — 배수지 물 사기 가격표에 '필터' 표시).
- 후일담: 배수지 벽 '끓여 마셔' 아래 '안 끓여도 됨'(A · B · C).

## 교차 정합(계획 때 점검할 것)
- 조수안(N-R01-032) 사망: 1-X 대체 = 조담희(SQ-S02에서 이미). 발동 쪽지 · 보고 · 보상은 조담희가 잇는다. 둘 다 없으면 게시판 공고로 끝(보상은 배수지 궤짝).
- SQ-S02와 같은 장소(배수지 · K-08) · 같은 인물(조수안): S02 진행 중 겹침 — S03 발동 장면은 S02 장면과 조건이 비켜 가게(S02 대화가 먼저, S03 한 줄은 ASK 메뉴에).
- K-08 이음 지점(S02 B)과 조사 지점 ②는 다른 칸.
- MQ-P4 곰팡이병 사실과 같은 변수(볼트 농장 곰팡이 = 프롤로그에서 본 사실) — 프롤로그에서 농장 곰팡이를 봤으면 '어디서 본 무늬' 판(이미 K-08 텍스트에 있음).
- 받고 안 하기: 시한 없음(원문). D만 30일 재발. 막 전환에도 남는다.
- 시간 도약: C 14일 마름 · D 30일 · A 너구리 7일 — 날마다 판정.
- 인터컴 방금례: 볼트 안 인물 — 1막에 볼트원을 죽일 수 없다(고정 지침) → 생사 걱정 없음.

## 재미 검수에 묻고 싶은 것

- 인터컴으로 고향(볼트)에 말을 거는 장면의 무게(F8 · F10).
- 해법 넷이 실제로 다른 느낌인가(F3) · D의 재발이 '벌'이 아니라 이야기인가(F9).
