## 1. 고칠 것
### D-416 적 재장전(탄창 단위)
- 적마다 `_mag`(무기 `mag`, 없으면 무한). 한 발 쏠 때마다 −1(산탄 · 연사 모두 한 번 쏨 = 1).
- 0이 되면 재장전 `reload_s × (1.2 − 0.004 × 스킬)`(스킬 45 → ×1.02) — 그동안 쏘지 않는다. 바크 하나('장전!' 류, 다듬이) · 총을 내리는 그림은 없으니 몸빛을 잠깐 흐리게(읽히게).
- 토큰이 없는데 탄창이 절반 아래면 미리 채운다(§7.4 '토큰이 없는 적은 … 재장전한다') — 토큰을 받을 때 막 비지 않게.
- 맵을 다시 열면 가득(저장하지 않는다 — 생성 적과 같은 결).
- 빼는 것: 진행기가 '쏘지 않는 판'으로 다듬은 적(보안요원 CR-473 위협 사격 · 감시포 fixed)은 그대로 무한(이야기 전투 박자). 보스 BOSS_ARMS 주무기는 재장전한다(깡철이 사냥총 5발 — 틈이 생긴다).
### D-417 사람 근접 예비 동작
- 양손 근접(계열 melee2 — 각목 W-046 · 야구 방망이 W-047 · 소방 도끼 W-049): 0.3초(§3.4 0.25~0.35 가운데). 한손 근접(melee1 — 쇠파이프 W-040 · 진압봉 W-041 · 야전삽 W-043)과 구울 맨손: 0.2초(원문에 한손 수치가 없다 — 양손보다 짧게, '읽히는 틈'만).
- 주기는 그대로(예비 동작을 주기 안에 넣는다 — 들개 `_bite`와 같은 꼴). 피해 그대로.

## 4. 조율사(계획 때) 반영 — 2026-10-28
- **재장전은 쉼을 대신한다**(쌓지 않는다): 탄창을 비운 발에서 반자동은 `_burst = 0`, 연사는 그 순간의 점사 쉼을 지우고 `쿨 + R`. 화력 배수 W-002 0.975 · W-017 0.88 · W-018 0.81 · W-025 0.55(한 주기 5.8초). 쌓으면 CR-437 3명 줄이 새 주의(15.8초) — 버림.
- **덧붙임**: 팔 손상이면 재장전 ×1.3(SD-11 — 주인공 규칙과 같게) · 경직 · 넘어짐 동안은 재장전 초가 멈춘다(`_shoot`이 돌지 않음) · 탄창은 무기 id에 묶어 늦게 채운다(무기 전환 · 시험의 무기 바꿈) · 바크는 기존 '딸깍.'(편마다 4초 · 40%).
- **빼는 적 더**: 파워 아머 CR-405('못 이기는 적') · 로봇(cmb.robot) · 감시포 fixed · 보안요원 CR-473. 연사 배수 빌린 무기(CR-436 · 534, W-002 ×1.5)는 탄창도 ×1.5(12 → 18). 생포 사격 계엄군 · 깡철이 사냥총 · 스토리 보스는 넣는다. 아군은 그대로 무한.
- **예비 동작은 호 판정과 묶는다**: 시작할 때 방향을 고정하고 내려칠 때 호(한손 90° · 양손 140°) · 닿는 거리 · 높이를 다시 본다 — 밖이면 헛스윙(쿨 = 주기 − 예비 동작). 계획 §2 3번('닿는 거리 밖이면 풀림')은 버림 — 사람 근접은 닿는 거리 1.2~1.5칸이라 뒤로 빠지는 데 0.3초 넘게 들어 그림일 뿐이었다. 옆으로 비키기: 한손 약 0.13초 · 양손 약 0.22초 — '미리 읽으면 피한다'. 무거운 양손(1회/초 0.7 이하) 0.35초.
- **MEL_CONTACT 50% 그대로**(예비 동작은 주기 안 — 제자리 셈엔 몫 없음). 도구 사수 실효: 반자동 `M / (M·c + (⌈M/3⌉ − 1)·1.3 + R)` · 연사 `M / (M/r + (M/(0.9r) − 1)·0.75 + R)`.
