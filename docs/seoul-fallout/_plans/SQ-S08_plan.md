## 원문과 이미 있는 원고의 어긋남(먼저 맞춘다)
- 명부 단말 TM-J04(1-4)는 김민수를 'A-14 민수 수선 점원 · 00:10 가족 찾으러 지상으로 · 명찰 두고 감'으로 적었다. 원문 S08은 '지하상가 경비원 · 10-24 사망 — 남쪽 통로 · 명찰 분실 2건 신고'. → 원문을 따른다: 김민수는 **상가 야간 경비원**, 00:10 남쪽 연결 통로 순찰 출발(무전 00:31 끊김) · 10-24 운영 일지 '순찰자 미복귀 — 사망 추정' · 관리 메모 '경비실 예비 명찰 2개 분실 신고'(그날 밤 경비실 서랍에서 사라진 예비 명찰 둘 = 두 사람이 단 명찰). '민수 수선'은 경비원의 어머니가 아들 이름을 따 붙인 수선집(A가 '명찰에 김민수라고 써 있으니 내 가게'라고 지키는 까닭 — 원래 원고 그대로 살아난다).

## 구청 창구(원문 네 방법 — 같은 목적의 대체 수단)
1. 번호표를 뽑고 기다린다: 대기 의자에 앉으면 화면이 어두워졌다 밝아지며 전광판이 한 칸씩(게임 시간 1시간). '0001번 손님' → 위동현 창구.
2. [화술 쉬움] '급한 민원입니다' → 위동현 '…규정상 급한 민원은 없습니다만, 오늘은 한가하니까요.'
3. M-073 관공서 출입 카드 → '공무원 우선 창구' — 바로.
4. 창구 뒤 서류함 [자물쇠 따기 25](카르마 −5). 위동현이 보면(목격 판정) '규정 위반입니다' → 창구 하루 폐쇄(`SQ_S08_SHUT` 다음 날 06시까지).
- 창구에서 받는 것: 2077 배급 기록 사본 둘(증명사진 대조 — 하경수 · 봉재민). 기록은 물건(M- 새 번호 없이 '읽을거리' 쪽지 둘 — notes)으로 손에 쥔다.
