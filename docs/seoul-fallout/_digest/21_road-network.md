# SD-21 도로망·고가 설계 — 요약 (원문 `21_road-network.md`)

**정본 범위**: 도로 노선·위계·폭, 시가지 결별 동네 길 생성, 고가(층 1) 구조·엔진 규칙, 도로 교체에 따른 장소·내용 재접속, 동선·밸런스 목표. SD-08 §6.3을 대신한다. 좌표·축척 SD-08 §3, 층 표현 SD-16 §6.5, 폭 SD-16 §6.7, 서사 SD-20.
**계기**: 리드 지시 2026-10-15 — 바둑판 동네 길 금지, 실제 서울 도로망, 고가 구현, 장소 이동까지 고려한 퀘스트·밸런스·플레이 경험.

**핵심 사실**
- 진단 D1~D4: 휜 직교 격자 동네 길(`world_bake.city`) · 청크 점열 14노선 · 고가 미구현 · 위계 없음.
- 원칙 R1 실제 노선(W2 변환, 손보정 없음) · R2 위계 · R3 바둑판 금지(실제 계획 격자 시가지만, 실제 방위각) · R4 2277 상태는 고정 배치 · R5 길 = 선택지(고가 빠르고 노출, 골목 느리고 발견) · R6 장소 기준점 불변(출입점만 옮김).
- 자료: 1순위 OSM(Overpass·Geofabrik, ODbL 크레딧) — **이 환경에서 차단, 리드가 허용 도메인 추가 필요** / 2순위 지식 웨이포인트(리드 승인 후). 저장소에는 추출·단순화 결과 `tools/data/seoul_roads.json`만.
- 위계 H1 도시고속 10~12타일 · H2 주간선 8~10 · H3 보조간선 6~8 · H4 집산 4~5 · H5 동네 길 3~4(생성) · H6 골목·계단 1~2(생성). H1은 입체 교차만.
- 결 F1 구도심 유기형(T자 분할·막다른 30%) · F2 언덕 등고선형+계단 · F3 계획 격자(여의도·강남·목동·잠실, 실제 방위각) · F4 공업 대블록 · F5 아파트 단지 순환로 · F6 시장·미로(막다른 50%). 판정: 경사 → 계획 목록 → zone → 나머지 F1.
- 고가: 상판(층 1)·기둥(층 0, 6~10타일 간격)·아래 그늘 통로·램프 8~14타일(층 이동 유일)·비상계단 32~49타일마다·끊긴 경간 4~12타일(멈춤, 낙하 없음). 층별 충돌·탄 막힘·다른 층 시야 ×0.5·층별 길 찾기·저장에 층.
- R01·R02 고가 E-01 올림픽대로 여의도·노량진 · E-02 서부간선 안양천 · E-03 신도림 환승 고가 · E-04 신림 사거리 고가 · E-05 도림천 2호선 고가 · E-06 노량진 다리목 램프.
- 길 고르기 목표: 시간 고가 1.0 : 간선 1.2 : 골목 1.6, 인카운터 1.3 : 1.0 : 0.6. 1막 구간 목표 시간 ±20%(봇 측정, 장소 대신 길을 고친다).
- 밸런스: 인카운터 배치 칸이 위계를 본다(추적대 H1~H3, 매복 H5·H6·고가 아래, 저격 고가 위), 빠른 이동 시간 = 실제 경로 길이, 추적대 등장 = 가까운 H2·H3 시야 밖.
- 재접속(§8): 문 자동 재부착(12타일 넘으면 경고), 손 맵 출구 위계 검사, spot 재배치, 생성 실내 재생성, 원고 길 묘사 대조, 봇 좌표 → 장소 ID, MQ-106 착륙 고가 제외.
- SD-20 점검(§9): 시간 약속·이미 아는 사실·한 곳 한 사람(층 명시)·저장에 층·P11 층 0 경로 도달성.
- 단계 1-Ra 자료 · 1-Rb 간선 굽기 · 1-Rc 동네 길 생성기 · 1-Rd 고가 엔진 · 1-Re 고가 그림 · 1-Rf 재접속 · 1-Rg 동선·밸런스 검증 · 1-Rh 기록. Rc·Rd·Re는 자료 없이 먼저.
