## 2. 요약·규모 (L37)
- 크리처 = **서울 사람이 실제 마주치는 생물의 변이**. 설화·요괴·신화 금지.
- 변이 원인 3개 고정: A 방사능 낙진 / B 중미 전쟁기 생물·화학무기 잔류물 / C 용산 미군 생물 연구 시료 유출.
- 규모: 크리처 15계통 60변종 + 환경 위험 5, 생물병기 2계통 7, 변종 7(+거인 4), 구울 7, 로봇·포탑·기체 30, 인간 적 11세력 58템플릿 + 추적대 11종, 보스 29(→ 총람은 30, §16), 이름 있는 NPC 7, 지역 변종 33. 적 DB 약 240행(L1760은 약 247) + 고참 판본.
- 실시간 맵 전투 전제. 계통마다 '예비 동작'과 '대응'이 다르다.
- 메인 연동: 관제망 로봇 G0~G5(5→6→7막 편성 변화), 계엄군 인도 분대 생포, 중국군 잔존병 MQ-303 해법으로 적대 해제, 호감도 '적대' 세력은 암살대·추적대.

### 표기 (L44)
- ID `CR-001`, 계통별 대역, 빈 번호는 확장용. 단계: 약/중/강/전설(원작 [BS] 상위)/유일(보스).
- 수치 칸: Lv, HP, 피해(1회, DR 전), DR(%), 속도(타일/초), XP.
- 권역: R01 관악, R02 여의도·영등포, R03 마포·상암, R04 서강·선유도, R05 도심(밀폐), R06 용산·남산, R07 강남, R08 동부, R09 북부 산악, R10 서부 평야, R11 청계산 + HR(한강 수역·섬·둔치), UG(지하철·지하상가·하수도·빗물터널).
- 시간대: 주(06~18), 황(17~20), 야(18~06), 상(상시), 실(실내 상시).

## 3. 설계 원칙·수치 체계 (L55)

### 3.1 원칙 6 (L57)
1. 서울 사람이 아는 생물(크기만 키워도 공포). 2. **설화·요괴·신화 금지**, 멸종 동물(호랑이·표범·늑대) 부활 변이체도 금지(호랑이 멸종 기록은 박물관 터미널 소품만). 3. 실제 특성 하나를 과장. 4. 서식지는 실제 생태. 5. 사람이 버린 동물의 후손(공통 주제). 6. 계통마다 예비 동작·대응이 안 겹침, **상위 단계는 행동 1개 추가**.

### 3.2 변이 원인 (L68)
- A 방사능 낙진: 2077-10-23, 탄두는 인천·평택·김포·용산 집중. 대형화·털 빠짐·변색. R10·공항 쪽 최심.
- B 생물·화학무기 잔류물: 중미 전쟁기(2066~2077). 방역 물자·해독제·고엽제류 비축. 독 강화, 발화성 독, 질병 매개 강화. 군수 야적장·방역 매몰지·화학 창고.
- C 미군 생물 연구 시료: 용산 생물방어 연구동 '헌터-킬러 생체 계획', FEV 시료 일부(C16 '미군이 들여온 시료' 수준). 피폭으로 배양액이 한강·도심 지하로. 갈퀴도마뱀, 강화 군견, 변종, 실패체.
- C 유출은 맥팔랜드 사건(2000)[S47] 모티브, 실명·시설명 금지, 영화 「괴물」 디자인 차용 금지. 원인은 겹칠 수 있고 겹칠수록 상위 변종 비율↑.

### 3.3 토종 대 외래 (L79)
- 물가: 토종 참게·자라·수달·가물치 / 외래 거북 떼·늑대거북·악어거북·황소개구리·뉴트리아·미국가재. 외래가 하천 대부분, **수달 = 깨끗한 물 지표**. [S20] 거북 523 중 64%(333) 외래.
- 땅: 토종 왕개미·왕지네·장수말벌·멧돼지 / 외래 붉은불개미·열대불개미·등검은말벌 → 영역 전쟁.
- 최상위 포식자: 토종 없음(현재 삵) → 군사 생물병기 갈퀴도마뱀이 한강 생태의 정점.

### 3.4 수치 체계 (L87)
- 플레이어 레벨 상한 35. 최대 HP = `90 + 지구력×20 + 레벨×10`(지구력5·Lv1=200, Lv20=390, Lv35=540). **HP 자연 회복 없음**(SD-11 §11.1). 위협도·레벨 범위·개방 문턱(1·5·9·13·18·23·28)은 SD-11 §10.4 정본. 방사능 Z1~Z5(SD-11 §11.2).
- 플레이어 속도(SD-11 §2.4): 걷기 3.0, 달리기(기본) 4.5, 질주 6.5(AP), 웅크림 1.5, 무기 넣고 달리기 5.0 t/s. 1t ≈ 1m.
- 피해 감소 `피해 × (1 − DR%)`.
- HP: 원작 대응 단계는 원작 HP. 원작 500 초과는 `500 + (원작 − 500) ÷ 2`(리버 1,100→800, 오버로드 1,250→875, 알비노 1,500→1,000, 베히모스 2,000→1,250, 여왕개미 1,000→750). V.A.T.S. 1차 제외(P8)가 근거.
- 인간 적 HP ≈ `20 + Lv × 8`(PA 병종 ×1.2, ±15% 랭크 조정). 원작 레이더 랭크1=25, 랭크3=85~90, 탈론 랭크3=135 재현. 단단함은 DR로. 예외: 철벽경호 랭크4, 이름 있는 보스.
- 레벨 35 확장: Lv23 이상 장소는 고참 보정 + 후반 전용(CR-176, 311, 316, 319, 325).
- 처치 시간 목표(스킬 50): 약 1~2초 / 중 3~6초 / 강 7~15초 / 전설 20~35초 / 유일 45~120초.
- DR: 몸 전체, 상한 85, DT 없음. 포유류·조류·물고기 0, **외골격 곤충·갑각만 5~20**, 로봇 0~25, 인간 방어구 3~38.
- 부위: 명중마다 가중치로 부위 추첨, 배수가 HP 피해에 곱해짐. **뒤쪽 90° 명중**은 머리 +10, 특수 부위 '등'. PW-D 뒤쪽 명중 시 껍질 70 중 40 → '배·꼬리 이음'(×1.0). **약점 창**: 공격 직후 0.5~1.0초 얼굴·머리 가중치 +20.
