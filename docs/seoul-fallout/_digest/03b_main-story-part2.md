## 7. 결말 슬라이드 (§7 L754)
### 7.1 조합 규칙
- 결말 + 카르마 + 세력별 최종 호감도 + 판도 + 인물·정착지 운명(바이블 §5.5). 원작 '카르마 3구간×사이드 1건'(RD-04 §3.9 비판 3)을 넘어 영향 준 곳마다 슬라이드.
- 1장 = 그림 1 + 문안 1~3문장. 문안 = 본문(결말별) + 꼬리(호감도 구간·상태). 상태 본문 슬라이드(볼트·어머니·잔존병 등)는 상태 본문 + 결말 꼬리.
- 호감도 3구간: **T1 적대·경계(≤-20) / T2 중립·우호(-19~+49) / T3 신뢰·동맹(≥+50)**. 정착지는 개별값, 정착지 연합은 AFF_JC.
- 카르마(V_KARMA_PRE7): 선 ≥+250 / 중립 / 악 ≤-250.
- **재생 순서·상한(최대 24장)**: ES-01 → 02 → 03 → 04 → 05 → 권역(ES-22~28 중 지배 세력이 시작과 달라진 곳 우선, 최대 3) → 세력(ES-06~15 중 대면한 세력, |호감도| 큰 순, 최대 6) → 정착지(ES-16~21 중 퀘스트 한 곳, 최대 3) → 사이드 슬롯(ES-33~48 최대 3; 순서 ① 마지막으로 끝낸 사이드 ② 판도 변화 최대 ③ 카르마 변화 최대; 동률이면 번호 작은 쪽) → ES-29 → 30 → 31(조건 맞는 줄 최대 3줄 한 장) → 32. 5+3+6+3+3+4=24.
- 배신판: `BT_<약호>`면 그 세력 슬라이드는 꼬리 대신 배신판 한 줄.
- 사이드 슬라이드 배정(RECON_SPEC §3.2): 04a ES-33~36, 04b ES-37~40, 04c ES-41~48, 04d는 새 번호 없이 ES-06~15 꼬리 변형. 문안 정본은 출처 문서.
- `{지배}` = 7막 시점 그 권역 지배 세력(SD-06 §5.8), `{정착지}` = 정착지 이름.
