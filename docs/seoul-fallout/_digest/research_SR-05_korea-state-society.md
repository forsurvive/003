## 1. 국가 체계 (L38)
### 1.1 정부 형태 (L40)
- 헌법 1948 제정, 1987 9차 개정. 대통령 직선 **5년 단임**, 국무총리(국회 동의). 대통령: 국가원수·행정수반·국군통수권자, 계엄 선포권(헌법 77조), 긴급명령권, 거부권. 국무회의(계엄 선포·해제 심의). 국회 **단원제 300명, 4년**(22대: 지역구 254·비례 46). 대법원(대법원장+대법관 13), 헌법재판소(9명). 중앙선관위, 감사원.
- 2025-09-26 정부조직법 개정: 19부 3처 20청 6위원회(48) → **19부 6처 19청 6위원회(50)**. 기재부 분리(기획예산처·재정경제부, 2026-01-02 시행). **환경부 → 기후에너지환경부**(에너지·원자력 정책 이관, 공포 즉시). **검찰청 폐지 → 공소청·중대범죄수사청**(2026-10께 예정, 시행 미확인). 성평등가족부, 과기정통부 부총리급.
- 메모: 부처명 잦은 변경 → 2077 가상 부처명('국가에너지원자력부', '국가재건부') 무리 없음.
- 헌정 사건: 2024-12-03 비상계엄 선포 / 12-04 국회 재석 190명 전원 찬성 해제 요구(약 2시간 30분 뒤), 해제 / 2024-12 탄핵소추 / **2025-04-04 헌재 8명 전원일치 파면**(2017 이후 두 번째) / 2025-06-03 21대 대선.
- 함의: 계엄·포고령·국회 봉쇄 = 최근 집단 경험 → **2077 설정은 가상 정권·가상 인물로만**.
### 1.2 수도 기능 (L73)
- 대통령 집무: 서울(2022 용산 이전, 청와대 복귀 여부·시점 미확인), 세종집무실(2027 착공·2029 입주 또는 2030 준공, 2026-07 설계 착수). 국회 여의도, **세종의사당 2033 목표**. 대법원 서초, 헌재 재동, 정부서울청사 광화문, 세종청사(2012~), 대전청사(청 단위), 과천청사, 한미연합사·주한미군사 평택.
- 요점: 정치·사법·경제 = 서울, 행정 실무 = 세종 '이원 수도'. 2004 헌재 '관습헌법' 결정 후 행복도시로 축소.
### 1.3 지방 행정 (L89)

### 1.4 비상 대비 (L99)
- 비상대비자원 관리법(국무총리 5년 주기 기본지침, 대통령 승인). **충무계획**: 기본계획(대통령, 국무회의) → 집행(주무부장관) → 시행(시·도지사) → 실시(시·군·구청장), 기밀 취급. 을지연습 = '을지 자유의 방패(UFS)'. 민방위기본법 1975.
- 2025 을지연습: 08-18~21, 약 4천 기관·58만 명. **08-20 14:00 공습경보 → 14:15 경계경보 → 14:20 해제**. 서울 전역 대피 14:00~14:15, 차량 통제 14:00~14:05. 특별재난지역 제외.
- 대피시설: 전국 약 1만 7천여(2024-08), **서울 2,910**(2025 서울시; 다른 페이지 약 2,975). 아파트 지하주차장·지하철역·지하상가·관공서 지하 = 기존 공간 지정. 1인당 도심 **0.825㎡**, 접경 정부지원 **1.43㎡**. 국민재난안전포털, 안전디딤돌 앱, 공공데이터(2025-11 갱신).
- 경보: 경계·공습·화생방·해제. 공습 = 파상음, 경계 = 평탄음(세부 미확인).
### 1.5 계엄 (L121)
- 헌법 77조·계엄법. 비상계엄(행정·사법 관장, 영장·언론·출판·집회·결사 특별 조치) / 경비계엄(군사 관련만). 국무회의 심의, 국회 지체 없이 통고(계엄법 4조). **국회 재적 과반 해제 요구 시 해제 의무**(77조 5항), 계엄법 11조. 계엄사령관: 국방장관 추천 → 국무회의 → 대통령 임명.
### 활용 (L132)
- 2077 정체 = "헌법 그대로, **비상계엄 장기화**" 또는 "충무계획에 따라 지하·지방 분산". 가상 연도·인물·기관명.
- 서울(정치·군사) ↔ 세종(행정) → 전후 세력 분화 씨앗(서울 지하 정부 잔존 vs 세종 관료 생존자, 맵 밖 소문).

## 2. 국방 (L139)
### 2.1 국군 (L141)
- 지휘: 대통령 → 국방장관 → 합참(군령) / 각 군 총장(군정). 해병대는 해군 소속, 별도 사령부.
- 병력: 2012 63만 9천 → **2022 50만여**(약 28%↓) → 2023 47~48만 → **2025-07 약 45만**. 2021 중기계획: 육군 2026까지 2개 군단·2개 사단 해체, 36만 5천. 해군 약 7만(해병 약 2만 9천), 공군 약 6만 5천(미확인). KIDA: 2038 약 39만 6천, 2040 27만 보도. 북한군 약 128만 vs 한국군 48~50만(약 2.6:1).
- 원인 저출산 → 간부 확대·첨단 무기·무인화.
### 2.2 징병 (L156)
- 병역법 18조. **육군·해병 18개월, 해군 20, 공군 21**(2018~2021 단축). 사회복무 21, 산업기능요원 34, 전문연구요원 36. 예비군 통상 8년, **약 310만**, 동원훈련 2박 3일. 민방위 상한 만 40세(일반 지식). 병영 용어가 일상어에 섞임.
### 2.3 한미동맹 (L169)
- 1950-07 작전지휘권 유엔군사령관 이양 / 1953-10-01 상호방위조약(1954-11 발효) / 1957 주한미군사령부 용산 창설 / 1978 한미연합사(CFC, 11-07 미확인) / **1994-12-01 평시작전통제권 환수**("제2의 창군") / 이후 CODA 6대 권한은 연합사령관 / 2018-06-29 주한미군사 평택 개관(용산 73년 마감) / 2022-11-15 연합사 평택 이전(용산 44년 종료) / 2025~2026 전작권 FOC 검증(결과 미확인).
### 2.4 전작권 (L183)
- 평시 = 한국 합참의장, 전시 = 연합사령관(미군 대장), 부사령관 한국군 대장. '조건에 기초한 전환': IOC → FOC → FMC. 전환 후 '미래연합사'(한국 사령관·미국 부사령관).
### 2.5 주한미군 (L189)
- 약 2만 8,500. 캠프 험프리스(평택, 해외 최대급), 유엔사·주한미군사·연합사 모두 평택. 오산(평택), 군산, 캠프 케이시(동두천). 용산공원. 서울 내 존재감 축소, 기지촌 상권 잔존.
### 2.6 방산 (L200)
- K2 흑표(폴란드 1차 2022 약 4.5조, 2025-07 2차 약 65억 달러), K9(폴란드 2026 현지 생산), K239 천무, K21·레드백, KF-21 보라매·FA-50, 수리온, 천궁, 세종대왕급·정조대왕급, 도산안창호급(3,000톤), 독도급, 155mm 포탄.

### 활용 (L220)
