## 3. 표기 규칙 (L47~L59)
- ID: `L-R08-01~34`, `L-R09-01~35`. 01~33 = SD-08 시드 순서, 34 이후 추가.
- 좌표 SD-08 §3.2 (tx, ty) + 청크 `C-xx-yy`. 보정(E2) 기본 0.
- **위협 → 적 레벨 = `clamp(플레이어 레벨 + 장소 보정, 하한, 상한)`**: 위협1 1~4 / 2: 3~8 / 3: 6~14 / 4: 10~22 / 5: 16~35.
- 등급(SD-16 §6.6): S 앵커 6+·실내 3~10 / A 앵커 3~5·실내 2~5 / B 앵커 1~2·실내 1~3 / C 앵커 1·실내 0~1.
- 마커 Y/N(N = 발견 XP 없음). 아이콘 SD-12 §5.4(1 볼트~22 기타). **`[경]` = SD-12 §9.5 경비 거점 플래그**(비무장 목격자가 경비에게 신고).
- 판도: `PD-R08-n`, `PD-Hnn`, SD-06 §5.9 거점(약호, 가중치). 사운드: BGM(X 탐험·S 정착지·D 던전·M 메인), BGS. 정착지·거점 BGM이 반경 안에서 탐험 곡보다 우선.
- 루팅 SD-13 §9 T1~T5. **신규 기록물 21건 = LR-79~99**(RECON_SPEC §3.4).
- 스킬북 `BK-nn` 번호: 01 물물교환, 02 중화기, 03 에너지, 04 폭발물, 05 자물쇠, 06 의학, 07 근접, 08 수리, 09 과학, 10 소형 화기, 11 은신, 12 화술, 13 비무장. (이 문서는 장소별 `BK-nn`만 쓰고 권역 순번은 없다.)
- 외형 코드 SD-07b §3 통일안(N-84), 로봇 `RB-<모델>·<표식>`. 훅은 ID 없이 이름, 세력 퀘스트는 SD-06 §13 FQ ID. 미부여 ID는 `(SD-xx에서 ID 부여)`.
