## 1. 컨셉 (L9~L16)
- "2277년 서울. 200년 전 전쟁의 명령이 아직 도시를 움직인다. 관악산 아래 볼트에서 자란 주인공은 잠든 '수도 관제망'을 깨울 단 하나의 열쇠로 지목돼 쫓기고, 마지막에 전쟁을 끝낼지, 누구에게 넘길지 결정한다."
- 시스템은 원작과 같다(볼트 프롤로그→오픈월드→퀘스트→카르마·엔딩 슬라이드). **이야기 구조는 다르다**: 부모 추적·정수 계획 없음, 주인공은 '모두가 쫓는 사람'.
- 월드는 프롤로그 직후 전부 개방. 목표: 장소 250+, 사이드 60+, 이름 있는 NPC 500+. **동료 시스템 없음**.

## 2. 설계 원칙 (L20~L29)
1. 시스템은 폴아웃 3 그대로(RD 세트). 바꾸는 건 무대·이야기.
2. 이야기는 새 구조. 원작 메인 뼈대·사이드 줄거리 미사용. 계승은 설계 패턴(다중 해법·카르마 분기·정착지 운명)만.
3. SR-01 캐논 체크리스트 C1~C16 준수.
4. 현실 기반. **설화·요괴·신화 금지**.
5. 2077년 한국. **1950~70년대 한국 레트로 풍속 꾸밈 금지**. 레트로 퓨처는 폴아웃 기술 규칙(원자력·진공관·로봇·파워 아머)으로만.
6. 실명 가상화: 실존 생존 인물·실제 기업·실제 부대명·작전 시설명 금지. 지명·공공 공간은 실명.
7. 고르지 않고 기운다(§5.8).
8. 제작 전제: 쯔꾸르 RPG **스타일**(엔진은 범용 2D, K9), PC+모바일(K10), 외부 심리스(실내 문 전환), 실시간 맵 전투(V.A.T.S. 선택), 장비 외형 반영, BGM·효과음(라디오는 음악 없이 텍스트 방송·징글, K11), 음성 없음.

## 5. 메인 스토리 (L135~L250)
### 5.1 주제 (L137)
- 200년 전 명령을 따르는 것들: 비상정부(분류 지침 부활), S-07(시험으로 관리자 양성), 연합단('기지를 지켜라'), 중국군 잔존병(관제 본부 파괴 명령), 관제망 로봇(전력이 들어오면 2077-10-23 계엄 집행).
- 마지막 퀘스트 이름 **〈종전〉**. 응답 문장: **"명령은 끝나지 않는다. 누군가 끝내기 전까지는."**

### 5.2 핵심 장치 (L149~L154)
- **수도 관제망**: 세진전자 2070년대 구축. 경비 로봇·포탑·차단벽·대피소 문·방송망을 광화문 지하 관제 본부 진공관 중앙 컴퓨터가 지휘. 200년 대기.
- **켜는 조건 3**: ①전원 = 당인리 재가동 ②본부 = 관제 본부 도달 ③관리자 = 살아 있는 '등록 관리자' 생체 인증.
- **등록 관리자**: 2077 관리자 전원 사망. 세진전자가 S-07 출생 등록 체계를 관제망에 연결. 200년 등록 계보에서 적성 평가로 뽑힌 1인 = **주인공**.
- **기본 프로토콜** = 비상 주민 분류 지침 → 볼트 밖 거의 모든 서울 사람이 적성 분자. 비상정부가 바란다.
- **숨은 대안**: 설계자(세진 수석 기술자, 2077 사망)의 **'시민 보호 프로토콜'**, 세진 타워 101층 수석 연구실 금고. 좋은 결말 조건.

### 5.3 구조·자유도 (L157~L176)
- 프롤로그 + 7막 + 에필로그. 막마다 목표 1·경로 여럿, 경로 하나로 막 넘어감, 나머지는 정보·호감도·보상.
- 자유도 원칙: ①월드는 프롤로그 끝에 전부 개방, 막은 지역 잠금 아님, 막는 건 위협도·한강·도심 밀폐뿐 ②목표 기반('무엇을 알아내라/확보하라'), 다른 경로로 먼저 이루면 퀘스트 갱신 ③순서 파괴 허용, 막 전환은 세계 상태 플래그 ④**메인 진행은 절대 막히지 않는다**, 최후 대체 = '단독' 경로 ⑤선택은 플레이로 기운다 — 가입·동맹·결말 메뉴·'어느 편' 질문 없음.
- 주인공은 처음부터 쫓긴다: 비상정부(데려가려), 연합단(지키거나 이용), 새벽인력(현상금).

### 5.5 엔딩 (L197~L209)
결말은 메뉴가 아니라 도착 시 세계 상태 + 콘솔 앞 행동.

| # | 결말 | 기울기 | 콘솔 행동 | 카르마 | 결과 |
|---|---|---|---|---|---|
| E1 | 계엄 프로토콜 가동 | 비상정부 '동맹'이면 육지환·남궁혁 곁. 아니어도 프로토콜 미교체 시 가능 | 기본 프로토콜로 인증 판에 손(또는 비상정부가 하게 둠) | 악 | 미등록자 소탕, '정통 대한민국', 서울 = 거대한 볼트 |
| E2 | 연합단에 지휘권 이양 | 연합단 '동맹' 또는 '신뢰' + MQ-508 주력 → 다니엘 서 곁 | 지휘 열쇠를 다니엘 서에게 | 중립 | 총으로 지킨 질서 |
| E3 | 시민 등록 | 프로토콜 테이프(또는 기록 8건 복원 사본), 정착지 연합 '동맹' 또는 '신뢰'+508 주력, 비상정부 무력화 | 테이프 꽂고 인증 | 선 | 모든 생존자 시민 등록, 서울 회의가 공동 관리 |
| E4 | 영구 정지(종전 선언) | 언제나 | 진공관 코어 파괴 또는 당인리 전원선 절단 | 선·중립 | 로봇·명령 정지, 맨손 재시작 |
| E5 | 관리자 군림 | 언제나 | 인증 뒤 열쇠를 넘기지 않고 관리자 등록 고정 | 악·중립 | 주인공이 관제망 주인 |

- 곁의 세력이 막거나 재촉(예: E4 시도 시 비상정부가 총을 든다), 대화·전투·은신 대응.
- 결말 슬라이드 = 결말 + 카르마 + 세력별 최종 호감도 + 판도 + 사이드 결과. 세력마다 호감도 구간별 슬라이드.
- 윤정인 생사·S-07 운명은 4막 행동으로.

### 5.8 선택의 원칙 (L239~L250)
사용자 지시(2026-10-12): "고르는 게 아니라 선택하는 거야. 선택은 선택지로 하기보다는 게임 플레이를 통해 자연스럽게 기울도록 해."
1. 진영 선택 화면 없음('어느 편', '제안 수락' 질문 금지).
2. 행동이 선택: 부탁 수행, 인도처(원자로 열쇠·테이프·정보·물자), 살해·구출, 거주·거래, 방송.
3. 세계가 먼저 알림: 인사·호칭·가격·순찰·방송·깃발·경비·판도 지도.
4. 결정적 순간도 행동(3막 현장 협력, 5막 곁에서 싸움, 6막 실제 진입로, 7막 콘솔).
5. 대화 선택지·스피치 체크는 유지, 개별 사안만. 대화 한 번으로 진영 결정 안 됨.
6. 작은 행동은 천천히, 지도자 살해·시설 파괴·탈취·핵심 물건 인도는 크게. 되돌리기 어렵지만 가능.
7. 양다리 허용, 적대 세력끼리 행적 인지(소문·방송·목격자) → 호감도 연동.
8. 아무 편도 안 들면 단독 경로.
