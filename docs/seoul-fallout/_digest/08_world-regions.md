## 3. 표기 규칙 (1.4 L67~74)
- 위경도는 일반 지식 근사값, **정밀도 ±수백 m(±10~20타일)**. '서울 사람이 알아보는 위치'를 지키는 값.
- 좌표: `(tx, ty)`, 청크 `C-xx-yy`, 청크 내부 `C-xx-yy:aa,bb`, 지하 `UG(tx,ty,z)`.
- 권역 코드 R01~R11(바이블 §4.2 순서), HR, UG. 격자 기호 `1~9, A(R10), B(R11), ~(HR), 5(R05)`.
- 위협도 1(안전)~5(치명). 레벨 하한은 14.4.
- **세력 코드**(SD-03a §4.5 판도 코드): 0 없음, 1 비상정부, 2 연합단, 3 원칙파, 4 지하시장, 5 각성회, 6 잔존병, 7 새벽인력, 8 정착지 연합, 9 약탈자, 10 변종, 11 관제망, 12 볼트 S-07, 13 주인공.
- 고정 명칭: 계엄사령관 **육지환**, 잔존병 지휘관 **멍쉐밍 상위**, 비상정부 라디오 **공보방송**. `(미확인)·†`는 SR 문서 표시 그대로.

## 4. 월드 설계 원칙 (2절 L78~90)
1. 실제 방위 유지: 모든 장소는 변환식 좌표. 손보정은 **±1청크(40타일)** 안, SD-09에 보정 벡터 기록.
2. 한 장의 균일 격자: 권역별 축척 차등 압축 **기각**. 밀도 차이는 장소 수·프리팹 밀도로.
3. 막는 것은 넷뿐: 위협도·한강·도심 밀폐·방사능. **퀘스트 진행으로 지역을 잠그지 않는다.**
4. 강은 진짜 장벽: 폭 약 1km 유지(수면 40타일 + 둔치). 건너는 길에 주인이 있다(원문은 "14개뿐", L85 — §8.2의 15개와 불일치, 9절 참고).
5. 산이 테두리: 북(북한산·도봉산)·남(관악산·청계산)·동(아차산). 서쪽 김포 평야는 방사능이 막는다.
6. 3도심(광화문 밀폐·여의도·강남) + 아파트 바다 + 가장자리 산지.
7. 판도가 보이는 땅: 모든 판도 구역에 검문·깃발·바리케이드·순찰 슬롯을 미리 둔다. 기울기는 슬롯 내용으로 보인다.
8. 처음 한 번은 걷는다: 강 횡단·도심 진입은 직접 통과해야 빠른 이동에 쓸 수 있다(SD-12 §5.6~5.7).

## 5. 좌표계와 축척 (3절)
### 5.1 축척 (3.1 L95~114)
- 월드 1t = 18.5m(동서 36.8km → 약 2,000t). 국소 1t ≈ 1.5m(SD-16 §3.2, 인물 키 40px). 압축 18.5÷1.5 ≈ 12.3배. 왕복 8차로 = 16타일(국소 24m, 월드 296m).
- 청크 40×40 = 740m 사방 = 0.548㎢(화면 가로 2장, 세로 3.6장). 월드 53×43청크 = 2,120×1,720타일(서울 경계 상자 36.8×30.3km + 사방 약 1청크 여백). 플레이 영역 1,230청크(약 674㎢, 한강 포함).
- 원작 비교: 원작 외부 약 51×51셀(셀 4,096 엔진 단위 ≈ 58.5m†), 체감 한 변 약 3km. 서울판 2,120t×1.5m ≈ 3.2km(국소 기준) → 걸어서 느끼는 넓이가 원작과 비슷. 지도 마커 원작 163 vs 서울 시드 425(마커 대상 약 300). 경계: 북·남·동 산지, 서쪽 방사능 평야, 경계 둑·철조망.

### 5.2 변환식 (3.2 L116~142)
```
φ0=37.566°(시청), 경도1°=111,320×cosφ0=88,235m, 위도1°=110,990m
원점(타일 0,0 북서 모서리)=위도 37.7080°, 경도 126.7550°, s=18.5m
tx=round((경도−126.7550)×4769.46)   ty=round((37.7080−위도)×5999.46)
역변환: 경도=126.7550+tx/4769.46, 위도=37.7080−ty/5999.46
청크: cx=floor(tx/40), cy=floor(ty/40), ID=C-{cx 2자리}-{cy 2자리}
```
- 투영: 등장방형 근사. 경도 길이 변화 0.2% 안팎 → 월드 끝 최대 약 4타일 오차, **보정하지 않는다**.
- 검산: 광화문(37.5759,126.9769) → 1058,793 → C-26-19. 남산 송신탑(37.5512,126.9882) → 1112,941 → C-27-23.
- **보정 규칙**: E1 기준점 12곳은 보정 0 고정(광화문, 남산 송신탑, 국회의사당, 여의도 금탑, 노들섬, 서울역, 용산 요새, 세진전자 타워, 관악산 연주봉, 북한산 백운대, 김포공항 크레이터, 청계산 매봉) / E2 그 밖 장소 최대 ±40타일, SD-09 장소표 `보정dx, 보정dy` 열에 기록 / E3 같은 청크에 장소 중심 4곳 이상이면 서로 8타일 이상 떨어지게 / E4 다리 양끝은 수면 폴리곤 밖 둔치, 다리 길이 ±10% 유지 / E5 한강 수면선·산 정상·성곽은 보정 안 함(장소를 옮김) / E6 R05 안은 같은 좌표, 구획 맵 바깥 테두리(잔해·차단벽)는 구획 사이 4~8타일.
