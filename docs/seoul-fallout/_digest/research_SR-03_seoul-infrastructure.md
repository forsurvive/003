## 1. 상수도 (L36)

### 1.5 뚝도 (L80)
- 1903-12-09 콜브란·보스트윅이 고종에게 특허권 → 대한수도회사 → 1908-08 제1정수장 완성 → **1908-09-01 급수 개시**. 완속여과, 하루 12,500톤, 사대문 안·용산 공급. 현재 정수센터 + 수도박물관(옛 송수실). '최초' 독립 학술 검증 못 함.
### 1.6 선유도 정수장 (L87)
- 가동 1978~2000(서남부 공급, 노후 폐쇄), 용량 미확인. 조성룡·정영선 안, 구조물 보존, **2002 개장**(4월/7월), '최초의 환경 재생 생태 공원'. 수질정화원·시간의 정원 등(미확인). 선유봉 채석설(미확인). **양화대교로만 연결된 섬**.
### 1.7 배수지 (L94)
- 1940 남산배수지 시작, 101개소 → 2022까지 108개소 계획. 2023 이후 기사: 공급량 96%가 103개소 경유. 상부 46곳 체육시설·공원(예: 대현산배수지공원). 산·언덕 꼭대기 지하 콘크리트 탱크.
### 활용 (L99)
- **선유도 정수장 = 제퍼슨 기념관 정화기(프로젝트 퓨리티) 1순위**(섬+다리 하나+수조). 2077엔 폐쇄 정수장을 국가 정화 연구 시설로 되살린 설정.
- 뚝도 수도박물관 = 전쟁 전 기록·설계도 '단서 던전'.
- 강북취수장·팔당댐 = 서울 밖 → "물의 원천은 성벽 밖" 확장 구도(후반 지역·DLC).
- 배수지 = 소형 정착지 물 공급원·무작위 탐색 던전.
- '아리수' 실명 금지 → 가상 정화수 브랜드.

### 2.4 청계천 (L138)
- 조선 준설 / 1907 이후 일부 복개 / **1958-05~1961-12** 광교~청계6가 본격 복개 / 1965~67, 1970~77 단계 복개(1978까지 설도) / **1967-08-15~1971-08-15 청계고가**(광교~마장동 약 5.6km, 폭 16m; 1969-03-22 삼일고가 870m 먼저, 이름은 삼일빌딩) / 2003-07 철거·복원 시작 / **2005-09-30 준공, 10-01 개방**, 823일, 복원 5,847m.
- 비판: 인공 하천(한강 물 정수 공급). 2025 복원 20주년 관광 명소.
### 활용 (L153)
- 신월 빗물터널 = 대형 던전 스펙. **대심도 빗물터널망 = 서쪽 폐허(양천·강서)↔도심 지하 동선**. 2077엔 강남·광화문 터널도 완공 설정 가능.
- 청계천 = 복개·고가·인공 하천 3층 겹친 협곡형 지역.
- 물재생센터 = 슬러지 크리처 소굴 또는 정화 기술자 정착지. 중랑 펌프장→과학관 = '박물관 겸 은신처'(언더월드 결).

## 3. 전력·에너지 (L161)
### 3.1 (L163)
- 전력자립도 2021 약 **11%**(약 90% 외부 송전). 2014 기사 4%대, 다른 기사 2.95%(기준 차이). 2024 사용량 **50,352GWh**. 서울 내 설비: 서울복합화력 약 0.8GW, 열병합(목동·노원·마곡, 미확인), 소수력·태양광. 변전소 현황 미확인 → 실명·실위치 대신 가상화.

### 3.4 원자력 연구 (L194)

## 4. 민방위 대피 시설 (L212)
### 4.1 규모 (L214)
- 공공용 대피시설 **약 3,033개소, 약 2,918만㎡**(2023-09-30).
- 소요량 = **1인당 0.825㎡** × 주민등록 인구(1일 미만 대피 가정). 이론 수용 2,918만÷0.825 ≈ **3,537만 명**(인구의 약 3.8배), 실제는 훨씬 적음. 2024 이후 총계 미확인(safekorea.go.kr, 공공데이터포털).
### 4.2 유형 (L220)

### 4.5 표지 (L247)
- 도안 미확인. 은평구 점자 표지 자치구 최초. 2011 연구: 접경 대피소 안내 없음.
### 활용 (L252)
- **핵심 세계관 차별점: "한국에는 볼트-텍 볼트가 없었다(또는 극소수)."** 볼트 대신 **지정 대피소**에서 200년 버틴 구조. 실험 문법은 소수의 정부·기업 전용 1등급 시설에만 → 희소성.

- 표지는 실제 도안 대신 노란 방사능 표지와 섞은 **가상 '민방위 피난처' 표지**를 맵 랜드마크로.
