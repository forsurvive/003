# 서울 폴아웃 기획서 핵심 색인 (00_INDEX)

> 이 문서는 `docs/seoul-fallout` 전체 기획서 세트의 **리마인드용 색인**이다.
> 원문을 대체하지 않는다. 규칙·수치를 구현에 쓰기 전에는 반드시 각 항목에 적힌 원문 절/줄을 다시 확인한다.

## 0. 읽는 법

1. **컨텍스트 압축 직후**, 그리고 **새 단계/기능 착수 전**에 이 색인을 처음부터 끝까지 읽는다 (`CLAUDE.md` 지침).
2. 착수할 기능과 관련된 `_digest/<문서>.md` 요약을 읽는다.
3. 요약이 가리키는 **원문 절**을 직접 열어 규칙을 확인한 뒤 구현한다.
4. 기획서를 고치면 해당 요약과 이 색인도 함께 고친다.
5. 구현이 기획과 달라지면 원문 해당 절의 "구현 정합" 블록과 `game/STAGE_0.md`에 기록한다.

### 정본 우선순위 (문서끼리 어긋날 때)

SC-00(세계관 정본) > SD-03a·03b(퀘스트·스토리) > SD-06(세력) > SD-08(지역·영역) > SD-09a~f(로케이션) > 나머지 시스템 문서.
같은 문서 안에서 어긋나면 **더 구체적인 표/수치 쪽**을 따르고, 이미 구현된 쪽이 있으면 구현을 기준으로 원문에 정합 메모를 단다.

### 개발 단계 계획

- 단계 계획·진행 기록: `game/STAGE_0.md` (0-1 ~ 0-12) · `game/STAGE_1.md` (1-1 ~ 1-13). 단계 0은 **0-12(자동 시험)까지 완료** — 남은 완료 기준은 3플랫폼 실기·외부 테스터·기준 기기 실측·화풍 검수(이 환경 밖). 단계 1(1막 MQ-102~106, R01·R02)은 **1-4(MQ-102·103 · 해킹 · 파밍 v2 · 길 위 발견물)까지 완료**, 다음은 1-5 MQ-104 여의도 지하 벙커(자물쇠 미니게임 포함).
