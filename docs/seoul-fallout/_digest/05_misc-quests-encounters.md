## 2. 개요·표기·원칙 (L27~78)
- 목적: 월드 충전재 3종(UQ·RQ·RE). 추가 임무 = **기울기 체감**(바이블 §5.8 원칙 3 '세계가 먼저 알려 준다').
- 1.3 요약 핵심 수치: UQ 124(13구역 4~14개씩). RQ 55. 반복 기울기: 회당 호감도 +2, 5회째마다 '단골 의뢰' +3(공개도 2, 연동 적용), 행동형 10회째마다 판도 사건 보정 +2. 주간 보상 곡선 1~3회 100%/4~5회 75%/6회~ 50%, **주간 RQ 캡 연성 상한 1,200**. RE 157종: 적대30·상인10·사건20·순찰10·교전10·추적대15·판도8·막반응16·날씨밤8·특수10·관제망10·에필로그10(고유 25, 반복 132). 기본 표 세력 비율: 지배·우세 60/25/15, 공백 크리처70·약탈자30. EP 64곳. 카르마 추적자 고정 매복 10곳(SD-06 §12.3 제안, 단 '성산대교 남단'→'공덕 오거리 고가'(SD-09b 제안)). 추적대 빈도: 호감도 적대 = SD-06 §4.5 하루 1회 판정, 수배 추격조 = SD-12 §9.7 등급별 0/5/10/15/20%, 카르마 추적자 = 3게임일마다 50%. 실시간 등장: 화면 밖 12타일 이상, 모퉁이 뒤 스폰, 방위 링 예고, 첫 분대 비적대 접근, 활성 상한 SD-14 §11.7(평시 12·16, 추적대 5).
- 1.4 표기: ID `UQ-01~`, `RQ-01~`, `RE-001~`, `EP-<구역>-nn`(신설, 예 EP-R01-03). 구역 R01~R11, UG, HR. 신규 인물은 `(SD-07b에서 ID 부여)`, 부록 A.

## 3. 공통 설계 규칙 (L81~149)
- 2.1 역할: UQ=퀘스트 목록 없음(SD-12 §3.12), 진행 중 '기타' 묶음에 사실 줄 1개. 시작: 대화·엿듣기 44, 장소·신호·사건·사물 17(01~61 기준). RQ='기타' 묶음에 의뢰처·이번 주 횟수. RE=표시 없음, 청크 경계 판정·고정 지점·막/판도 사건.
- 2.2 금지/대체(L91): 물건 다툼 → 메뉴 금지, 들고 각 인물에게 '건네기'(확인 대사 "이걸 맡기겠다" 1줄, SD-06 §3.9). 세력 교전 → 실제 쏜 대상·스팀팩 쓴 대상이 편든 기록, 그냥 지나가면 기록 없음. 반복 의뢰처 여럿 → 어느 창구에 내놓는지. 도덕 시험 → 선/악 버튼 금지, 개별 사안만(바이블 §5.8 원칙 5). 기록 문장은 사실 문장("철사의 돋보기 렌즈는 아직 당신 가방에 있다.").
