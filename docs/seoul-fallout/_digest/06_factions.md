## 4. 호감도 시스템 (L140)
### 3.1 원칙 7 (L142)
1. 숫자는 내부 값(-100~+100). 호칭·가격·순찰·방송·깃발·핍-보이 한 줄. 수치는 옵션 '관계 수치 보기'(기본 꺼짐).
2. 묻지 않는다: 가입·입단·동맹 선택지·수락/거절 버튼 없음. 승급은 세력이 먼저 계급장·복장 건넴(4.4).
3. 행동이 쌓인다(부탁·인도·살해/구조·거래·숙박·방송).
4. 작은 것은 천천히(일상 하루 +6), 큰 것은 크게(지도자 처리·시설 탈취·핵심 물건 인도, 3.9).
