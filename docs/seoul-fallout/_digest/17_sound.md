## 2. 요약·결정 (L15~L29)
- **실존 곡 0곡**: 원작 스코어·수록곡·실존 대중가요·군가·국가·CM송의 음원·편곡·멜로디 인용 모두 금지.
- 시대 표지: 1950~70년대 한국 레트로(트로트·뽕짝·엔카풍 꺾기·그룹사운드·통기타 포크) 금지. '세기 중반 미국풍' 어휘 위에 스코어·징글, 2077년 한국은 방송 문안·생활음으로.
- BGM **135큐(루프 111 + 원샷 24)**. 결말 = 콘솔 앞 행동 → ME-E1~E5 → BGM-E00 5판(같은 조성·템포).
- BGS 루프 **68**. 라디오: 방송국 4 + 국지 신호 6, **음악 채널 없음(바이블 K11)**, 징글 16·신호 베드 5·감정 스팅어 15. 수록곡·가상 가수·보컬 없음.
- 라디오 v0.4 역할: 호감도 수치 숨김 → **라디오가 기울기를 알림**. 뉴스 5종 약 280편.
- **음성 없음**: 텍스트 자막 + 시그널 징글 + 신호 베드 + 감정 스팅어.
- 효과음 **567파일**(P1 334). 동료 없음 → 진돗개·파수-3은 NPC 소리 세트, 지원 병력은 호출음 + 세력 모티프 스템.
- **시그니처 = 관제망 4음 차임(LM-01)**: 관제망이 말하는 모든 순간 같은 4음.
