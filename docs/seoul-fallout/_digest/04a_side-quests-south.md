## 0. 머리
- **범위**: 한강 남쪽 4권역(R01·R02·R07·R11)의 지도 표시 사이드 퀘스트 **25편 SQ-S01~S25** 상세. 카탈로그(SD-09a·09d) 훅 71개(H-R01 16, H-R02 15, R07 주 15 + 소형 12, R11 13) + SD-06 §13.1 연계 후보 합침. 퀘스트별 발동·단계·해법·결과·카르마·호감도·판도·정보 전파·보상·대사·연출·연계. 거처 획득 지정, 학습형 배치, 남는 훅 SD-05 이관 목록 포함.
- **다루지 않음**: 메인(SD-03a·03b), 세력 FQ(SD-04d), 비표시·반복·랜덤 인카운터(SD-05), 다른 권역 사이드(SD-04b·04c), 장소 구조·좌표(SD-09a·09d), 수치 공식(SD-06·SD-10).
- **정본 관계**: XP 단가 SD-10 §4.4 / 판정 요구치 SD-10 §3.6 / 호감도 기본값·연동 SD-06 §3.4·§3.6 / 판도 SD-08 §15.2·SD-06 §5.2 / 공개도 SD-06 §6.2 / 세력 코드 SD-03a §4.5 / L-ID SD-09a·09d / C-ID SD-07a, 새 인물 ID SD-07b / 아이템 ID SD-13(새 ID는 RECON_SPEC §3.5 배정) / 적 SD-14 / 로그 문체 SD-18 §8.3. RECON_SPEC §3.1(SQH 코드)·§3.2(ES 배분)·§4.1 N-18·§4.2 N-42·N-67·N-71 확정 사항 반영.
