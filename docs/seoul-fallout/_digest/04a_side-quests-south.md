## 0. 머리
- **범위**: 한강 남쪽 4권역(R01·R02·R07·R11)의 지도 표시 사이드 퀘스트 **25편 SQ-S01~S25** 상세. 카탈로그(SD-09a·09d) 훅 71개(H-R01 16, H-R02 15, R07 주 15 + 소형 12, R11 13) + SD-06 §13.1 연계 후보 합침. 퀘스트별 발동·단계·해법·결과·카르마·호감도·판도·정보 전파·보상·대사·연출·연계. 거처 획득 지정, 학습형 배치, 남는 훅 SD-05 이관 목록 포함.

## 2. 개요·표기·원칙 (L29~L106)
- **1.2 요약(L36)**: 25편 = R01 7(S01~S07)·R02 6(S08~S13)·R07 7(S14~S20)·R11 5(S21~S25). 훅 71 중 33개 사용(합치기 포함, R11 훅 4 일부 흡수) + SD-06 §13.1 후보 3(생활기록부 열람·이중 입찰·폭주 신호). 남는 훅 38 → 부록 B(SD-05, 일부 04b·04c). 권장 Lv 3~20, 학습형 9편 Lv 3~10. **XP 합계 약 11,100**(완료분만; 판정·처치 XP 별도). 거처: 봉천 S02(대체 경로)/세이프빌 S14(112동 1503호, 조건③ 신설 확정). SQH 13종, SQE 6종, ES-31 줄 6 + ES-33~36. **진영 질문 0건**, 로그는 사실·상태형.
- **1.3 표기(L49)**:
  - `SQ_S01` 단계: 0 미발동 / 10 발동 / 20~90 진행 / 100 종료 / 200 보류 / 250 닫힘. `SQR_S01` 해법·결말 코드, `SQS_S01` 순서 파괴.
  - 로그: 핍-보이 DATA>퀘스트 목표, 한 줄 30자 이하, 사실·상태형.
  - 판정: 고정 요구치 15/25/50/75/100(SD-10 §3.6). 화술은 확률식, 화면 `[화술 45%]`. `[증거: 물건]` = 화술 한 단계 하락 또는 자동 성공.
  - `BC +8` = 호감 직접 변화(보정 전). 정착지 개별 약호 `AFF_JC_<약호>`(BC 봉천, SA 사당, SV 세이프빌, YJ 양재 온실촌 등).
  - 연동 = SD-06 §3.6 계수, 세력이 **알게 된 때** 적용.
  - 판도 `PD-R01-2 정착 +5` = 사건 보정, 7일마다 0 쪽으로 2씩 감소.
  - 공개도 0 비밀/1 목격/2 공개/3 방송급.
  - 새 아이템 ID 대역(RECON_SPEC §3.5): 퀘스트 M-301~M-321, 잡화 M-162·M-183~185·M-189, 머리 장비 A-084~086, 소모품 I-085.
- **1.4 규칙 S1~S7(L67)**:
  - S1 묻지 않고 시작: 발동 = 엿들음·게시판·물건·부탁·우연 목격. 부탁형 선택지는 "자세히 듣는다/나중에"뿐, "나중에"도 로그에 '들은 사정'.
  - S2 로그는 사실만("○○가 △△에 있다", "□□는 지금 당신 손에 있다"). "구할지 정한다/누구에게 줄지 선택한다" 금지.
  - S3 결과는 손과 몸: ①실제 건넨 상대(물건 주기·보관함/책상·두고 떠나기·파기) ②살리거나 쓰러뜨린 사람 ③데려다준 곳 ④방송·게시판에 실제 올린 내용. 확인 대화는 "이걸 맡기겠다" 한 줄.
  - S4 해법 셋 이상, 진행 막는 판정엔 다른 길 둘 이상(SD-10 §3.6 원칙 2).
  - S5 아무것도 안 해도 결과(시간 지나면 '주인공 없이' 닫힘).
  - S6 세계가 먼저 알려 줌: '기울기 체감'(호칭·가격·순찰·깃발·방송·게시판). 숫자 팝업 없음.
