# [digest] SR-02. 서울 지리·도시 구조

## 머리
- 문서 ID: SR-02 / 조사 자료 / 작성일 2026-10-12. 버전 표기 없음.
- 다루는 것: 현실 서울(현재 기준)의 면적·인구·경계·25개 구, 수도권 인접 도시, 자연 지형(한강·섬·지천·산·분지), 한강 다리·강변 도로, 권역 구조·주거 형태, 랜드마크·시설, 교통(지하철·도로·터널·철도역·공항), 축척(거리), 원작 수도 황무지 대응.
- 다루지 않음: 서울 역사 연표 전반, 생물·생태, 한국 사회·정치 제도, 군사 시설 상세(공개 정보만).
- 관련/정본: RD-12(원작 월드 구조 — 원작 구조 근거는 RD-12 2장), RD-13(장소 카탈로그), RD-27(이식 메모).

## 표기 규칙 (L9)
- 표시 없음 = 웹으로 확인. **†** = (미확인)과 같은 뜻, 검색 한도 소진으로 재확인 못 한 일반 지식 → 수치·연도는 상세 기획서 옮기기 전 재확인 필요. **(미확인)** = 자료 간 엇갈림·근거 약함. 자료별 차이는 범위로(예: 남산 262~265m).
- 7절 거리 = 근사 좌표 **직선거리**. 실제 도로는 1.2~1.5배. 축척 감각치 전용.
- 기관·기업명은 사실로 적고, 가상화는 각 절 '기획 활용 포인트'에.

### 1.4 수도권 (L91)
- 수도권 = 서울+인천+경기. 2025년 말 수도권이 비수도권보다 100만 이상 많아 전국(51,117,378)의 절반 넘음. 서울=일자리·교통 중심, 위성 도시 구조.
- 인접: 북서 고양(일산†, 킨텍스†, 행주·방화대교) / 서 김포(김포골드라인†) / 서 부천·인천(경인 축, 인천항, 인천공항 영종도 2001†) / 서남 광명(KTX 광명역†) / 남 안양·과천(정부청사†, 서울대공원†) / 남동 성남(분당·판교†, 서울공항) / 동 하남·구리·남양주(팔당댐 상수원†, 미사·다산†) / 북 의정부·양주(중랑천 상류, 1호선 경원선).
### 1.5 활용 (L107)
- '한강이 가르는 두 도시' = 원작 포토맥처럼 강북(역사·정부)/강남(전쟁 전 부유층) 세력 분리.
- 서쪽만 열린 분지 → 맵 경계는 산, 서쪽은 하구 평야.
- 25개 구 대신 **8~12개 '게임 권역'** (쯔꾸르 규모).
- 구 이름은 그대로 가능, **아파트·대학·병원 브랜드명은 가상화**('한강 제3단지', '관악국립대학').

## 2. 자연 지형 (L115)
### 2.1 분지 (L117)
- 이중 분지: 작은 분지 = 내사산(북악·인왕·남산·낙산), 청계천 서→동, 한양도성 약 18.6km†. 큰 분지 = 외사산(북한산·관악산·용마산(아차산)·덕양산)†, "8개 산과 한강 평야·서쪽 저지".
- 고도: 한강변·여의도·잠실 수 m~20m대†, 상습 침수(강서·양천·영등포·강남역 저지)†. 도심 수십 m†, 북쪽 산 500~800m대.
- 주요 산 화강암 바위산. 기후: 장마·집중호우, 한강 결빙 드묾†(상세는 다른 SR).
### 2.2 한강 (L128)
- 497.5km, 서울 41.5km(기사 41km). 동(암사·강일)→서(개화). 두물머리†→팔당→서울.
- 강폭 약 1km 안팎(공식 실측 미확인). 다리 예: 잠실대교 1,280m, 잠실철교 1,270m, 잠수교 795m.
- 시내 하천 총연장 약 78km(지천 37km). 1980년대 한강종합개발†: 제방·고수부지·강변도로, 한강공원 11곳†.
- 수중보: 신곡수중보(하류)†, 잠실수중보†(위쪽 상수원 취수 구간†).
- 옛 이름 욱리하·아리수, 나루 160곳 넘음(1994 기사, 출처 목록엔 162곳).
