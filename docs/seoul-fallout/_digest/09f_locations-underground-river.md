- NPC: UG 56(N-UG-001~056), HR 44(N-HR-001~044). 타 문서 출처 4명(무쇠·백인하·노윤기·물개) 포함.
- 훅: UG 16, HR 14. 진영 선택 장면 없음, 원작 리스킨 없음.
- 지하철 1~5호선. 지하 입장 역 51 + 정착지·시설로 쓰인 역 2. U01~U20 L-ID 매핑.
- 횡단로: X06만 L-UG-09, 나머지 L-HR.
- 수집품: 흔들인형 1(CL-12), 스킬북 UG 20·HR 7, 고유 무기 3(W-105·W-126·W-128).
- **표기 규칙(L69~L85)**:
  - L-ID = SD-08 §11 시드 순. 추가 시드는 끝 번호.
  - 좌표 (tx, ty)+청크. UG는 지상 입구(또는 지상 투영) + 깊이 z(SD-08 §3.4: −1 지하상가 / −2 얕은 역 / −3 깊은 역 / −4 대심도).
  - 위협 1~5 → 레벨(SD-08 §14.4): 1: 1~4 / 2: 3~8 / 3: 6~14 / 4: 10~22 / 5: 16~35.
  - 마커 Y/N. SD-12 §5.4 아이콘 번호: 6 지하철역 / 7 지하상가·지하 시설 / 1 볼트 / 18 동굴·터널 / 3 소형 정착지 / 2 대형 정착지 / 15 다리·횡단로 / 17 강변·섬 / 12 기반 시설 / 16 자연 / 22 기타.
  - 등급(SD-16 §6.6): S 앵커 6+·실내 3~10 / A 3~5·2~5 / B 1~2·1~3 / C 1·0~1.
  - 판도: 지상 투영 청크의 `PD-Rxx-n`(SD-08 §15.2), 거점 `PD-Hnn`(§15.3), SD-06 §5.9 거점(가중치). HR 청크엔 판도 구역 없음 → 횡단로·거점만.
  - 소리: SD-17 BGM/BGS. 정착지·거점 반경에선 BGM-S 우선.
  - 루팅(SD-13 §9.2): UG = 인접 지상 권역 등급 −1(하한 T1)~인접 권역 상한, HR = T2~T3. 레벨 7·13·19·25에서 한 단계씩 오름.
