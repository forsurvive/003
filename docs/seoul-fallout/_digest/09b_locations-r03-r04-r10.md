## 2. 공통 규칙·표기 (L46~L94)
- **좌표** `tx·ty`는 SD-08 변환식. 이 문서 장소는 **모두 보정 0**(같은 청크 4곳 이상 없음, 다리 끝 장소 없음).
- **마커** Y/N. N = 구역 진입 알림만, **발견 XP 없음**.
- **등급** S/A/B/C(SD-16 §6.6 앵커 수·실내 맵 예산). 판도 `PD-Rxx-n`, 거점 `PD-Hnn`. BGM `BGM-X..`(탐험)·`S..`(정착지)·`D..`(던전), BGS.
- **방사능 대응**: Rad-1=Z1, Rad-2=Z2(실내 침수 Z3), Rad-3=Z3~Z4, Rad-4=Z4~Z5.
- 적 = SD-14 CR-ID, 레벨은 SD-08 §14.4 범위 안 SD-14 §11.1 산정식. 아이템 W-·A-·I-·M-, 수집품 흔들인형 `CL-nn`, 스킬북 `BK-nn`+권수(배치 ID 안 씀). 흔들인형 정식명 **'든든이 입주 기념 흔들인형'**(옛 '한결이' 교체, N-29). 기록물 `LR-nn`.
- NPC ID `N-R03-001` 형식. 주요 인물은 C-ID 병기. 주 N-ID가 다른 문서에 있으면 결번(예 C-033 허문경 → N-R03-031 결번).
- 외형 코드 `몸-피부-머리-머리색-몸통-낡음-팔레트-머리장비-눈장비-소품`(SD-07b §3 통일안: 몸 M1·M2·F1·F2·E1·E2·K1, 구울 SG1·SG2, HR00~11, 낡음 0~2, HD00~18, EY00~08, PR001~200). 로봇 `RB-<모델>·<표식>`.
- **이름 교체**: 육지환(구 강태오), 멍쉐밍(구 천웨이), 공보방송(구 국민방송), '부위 손상'(구 '불구'), 원칙파 약호 WP.
- **발견 XP**: 일반 10, 주요(정착지·볼트·S·A 던전·전망 지점) 25.
- **루팅 레벨 연동**: 권역 기본 등급에서 플레이어 Lv 7·13·19·25마다 +1등급, 권역 상한에서 멈춤(SD-13 §9.2). 장소별 '루팅'은 고정 상한·고정 배치만.
- **정착지 소유물**(탱크마을·선유도·망원): 절도 적발 시 개별 호감도 -5, 신고형 목격자(SD-12 M-14).
- **금지**: 망원동 실제 수해·신월 빗물터널 실제 공사 사고를 연출·퀘스트 소재로 쓰지 않음. 침수 연출은 SD-08 §8.1 수위 이벤트와 볼트 실험(S-11)만 근거.

## 7. 원작 대응 (L1251~L1276)
- 당인리 = 제퍼슨 기념관 역할(다층 던전·세력 대치·월드 변화). 차이: 물이 아니라 전기, '열쇠를 누구 손에 두고 나왔나'가 판도. **희생 장면 없음**.

- 난지도 = 레이더 거점 + 바퀴 왕. 흰 깃발 교섭·고철 거래로 '거래가 되는 약탈자'(NJ).

- 공항 = 서부 고방사능 평원·공군기지(확장판). 미군 화물(팻맨·T-51b·실험용 다탄두). 약탈자 두목 관제탑, **메인 없음**.

- 밤섬 = 수생 크리처 대둥지. **알을 두고 떠나면 전투 없이 끝**.
- 훅 비교: 〈5호 탱크 바닥〉(폭발물·폭파 선택 없음, 비축유 유출 조사) / 〈전방 위문품〉(가상 현실 아님, '종전' 증거) / 〈여왕의 페로몬〉(생태 해법만 공유) / 〈옥상의 가족〉(노예 구출 습격 아님, '이주 알선') / 〈물이 차오르는 볼트〉(인도처가 결과).
- **원칙: 세력을 고르는 장면이 있는 훅 없음. 결과는 물건의 인도·함께 싸운 쪽·시설 상태로만(바이블 §5.8).**
