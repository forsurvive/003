## 0. 핵심 결론 (L9)
- 공식 설정에 '2077년 한국' 없음. Pre-War countries 목록에 남·북 모두 없음. 게임 내 한국 언급 = FO76 윈디 박('바람')과 쪽지(한복·조선·추석)뿐.
- 한국전쟁 발생 여부 공식 미정. 분기는 '2차 대전 직후'만. 위키 분쟁 목록은 2차 대전 → 자원 전쟁.
- 한반도에 직결되는 공식 사건 = 중미 전쟁(2066~2077). 2074 중국 본토 상륙(산터우·난징·상하이·양쯔강·고비), 2077-10 필리핀 맘바하오 제5보병. **미군 진입 경로·기지는 공백** → '한반도 전진기지' 자리.
- 중국은 주변국 병합. 2076 T-51 투입 뒤 병합국 보급선 붕괴·반란([D]). 병합국 이름 없음 → 한국을 병합국으로 둬도/아니어도 충돌 없음.
- 볼트는 미국(+병합 캐나다)에만 근거. 한국 볼트는 '수출판·라이선스판' 새 설정 필요.
- 선제 발사 주체 공식 미정(FO4 스위치보드는 주체 미기재, 바이블 "모른다"). 팀 케인은 '중국 먼저' 개인 의견, 정사 결정권은 베데스다.
- 전후 미국 밖은 거의 공백. 바이블 작가가 의도적으로 비움 → **2277년 서울은 설계 재량 최대**.

## 2. 분기·세계 규칙 (L43)
### 2.1 분기점 (L45)
- 분기: 2차 대전 뒤, 시점·방식 비공개[D]. 1951년 이전 분기 부정은 [W] 추론(프리덤 트레일).
- 분기 이전(독립전쟁~히로시마·나가사키)은 현실과 동일[G]. 작은 차이: 외계인 제타, 우바르.
- 냉전 사건 특정 안 됨. 베트남전은 택틱스(비정사)만, 놀런: "베트남전·워터게이트·히피 없이 아이젠하워 기세로 2077까지".
- 한국전쟁: 게임 내 언급 없음(공백).
- 1969년 50개 주 → 13개 연방, 성조기 '원형 13별+가운데 1별'. 소련 2077까지 존속(영향력은 중국에 밀림). 중국은 마오 체제 유지, 개혁·개방 없음. 유엔 2052-07 해체[G:FO3].

### 2.3 문화·정치 (L81)
- 1950년대 미국 문화 2077까지 지속.
- 반공·적색 공포: 리버티 프라임 "공산주의보다 죽음이 낫다!", '경계하는 시민 신고 전화', 'Know the Signs!'.
- 대통령령 99066호: 중국계 강제 수용(터틀도브 수용소).
- 기업·국가 유착. 2076-08 식량·에너지 폭동 → 비상사태·계엄 → 2077-01-22 시위대에 파워 아머 첫 투입.
- 인플레: 휘발유 갤런당 8,500달러, 코르베가 199,999달러.
- PTSD 언급, 보스턴 버글 「원자 최후통첩」 사설.
- 활용(L90): 2077 한국도 기술 규칙 준수. 스마트폰·인터넷·평면 디스플레이·K-팝 산업 성립 안 함. "폴아웃 기술 위에 실제 서울 공간을 얹는" 방식(진공관 은행 전산실, 소형 원자로 버스, 가정용 로봇 아파트). 1945 해방까지 현실, 이후(분단·한국전쟁·산업화) 설계 대상. 사용자 지시 '1950~70년대 레트로 최소화'와 부합. 반공·밀고·화교 감시 등 이식 가능하나 서술은 사실 위주·중립.

### 7.2 자유 설계 영역 (L449)
- 매우 큼: 한국전쟁 발생·결과, 분단·북한 존재, 1950~2077 체제·경제·도시(C7 안에서), 2078~2277 한반도 역사.
- 큼: 진영(동맹/중립/병합), 중미 전쟁 참전, 2077-10-23 피해(시각은 C1), 대피 시설(볼트-텍이면 C9), 변이 생물(FEV는 설명 필요), 중국 잔존 세력 활동.
- 중간: 일본(미국 쪽/중립 권장), 대만·필리핀(필리핀은 미군 주둔지 자연스러움), 소련 극동(C11 준수).
- 활용: 컨셉서에 '정사 고정값'과 '우리 결정값'을 나란히 관리. 최대 결정 = 분단 여부(분단: DMZ·공산권·병합 소재, 민감 / 통일: 민감도 낮고 '중국과 국경 맞댄 미국 동맹국').

## 8. 한반도 전진기지 검토 (L473)
### 8.1 맞물림 (L475)
- 2052 유엔 해체 → 한미 양자 동맹 강화 / 2059 → 한국에 기지 확대·자원 협력 압박(캐나다 거울) / 2066 → 감시 거점, 견제 공격 대상 / 2067 파스칼 → 정보 공작 근거 / **2074 → 인천·평택·부산 항구·비행장이 상륙·보급 집결지, 서해 건너 산둥·상하이·양쯔강 하구 최단 경로(경로는 공식 공백)** / 2076-06 → 파워 아머 수송·정비 거점 / 2076-08 → 한국 동원·징발·반전 시위·계엄 / 2077-01 → 상하이·난징 병력 경유 / 2077-10 → 최고 경계, 헤이구이 침투, 잠수함 / 2077-10-23 → 중국 1순위 표적, 미 동부보다 먼저 맞았을 수도(C1·C3 준수). 모두 한반도 부분은 창작.
