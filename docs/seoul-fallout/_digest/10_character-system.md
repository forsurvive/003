## 2. 핵심 결정·원칙 (L9~L66)
- 전제: P6 심리스 월드, P7 실시간 맵 전투, P8 V.A.T.S. 1차 제외. 이에 안 맞는 것만 재해석.
- S.P.E.C.I.A.L. 7종 그대로(각 1~10, 기본 5 + 추가 5 = 40). AP = 질주·회피·집중 사격·파워 공격 자원. PE = 탐지 반경, CH = 호감도 획득량·지원 병력에도 작용.
- 스킬 13종 계승(통합 안 함). 비무기 체크 I~V 고정 요구치(자물쇠 0/25/50/75/100, 나머지 15/25/50/75/100). 화술만 확률식.
- 레벨 상한 35(U1 해소, N-04). 필요 XP `50 + 150 × 현재 레벨`. 레벨업 HP +10, 스킬 포인트 `10 + 지능`, 퍽 1.
- 퍽 119: 원작 일반 72 중 71 계승·변형(V.A.T.S. 의존 9종 재해석), 퍼피스! 삭제. 신규 31(생활·제도 24 + 호감도 연동 7). 특별·퀘스트 9. 세력 비기 8(동맹 도달 시 자동).
- 카르마 −1,000~+1,000, 5구간, 칭호 105(Lv1~35 × 3). 카르마 = '주인공이 어떤 사람인가', 호감도 = '세력이 주인공을 어떻게 보는가'. **둘은 따로 움직인다.**
- **바이블 반영(L28~L36)**: MQ ID `MQ-<막><순번>`, 프롤로그 MQ-P1~P4, 에필로그 MQ-E1 / **동료 시스템 없음**(일시 동행 NPC·세력 지원 병력만) → 동료 규칙·퍼피스! 삭제 / 호감도 −100~+100, 6단계(SD-06), 카르마와 분리 / 월드 전부 개방 → 체크·레벨 목표를 막이 아니라 권역 위협도 기준 / v0.4 '고르지 않고 기운다': 세력 전용 퍽·배타 택일 없음, 비기 자동 습득, 호감도 퍽 설명은 체감 효과(수치는 데이터 열) / 주인공 = 한유리 박사 동생 **한유정의 후손**(관리 계보 1), 계보는 숨은 설정이라 등록번호에 넣지 않음(N-09), 적성 평가는 겉치레지만 태그는 정상 결정, 돌잡이는 이동 튜토리얼(능력치 영향 없음).

## 3. S.P.E.C.I.A.L. (L69~L235)
### 3.1 기본 규칙 (L71)
- 7종 ST·PE·EN·CH·IN·AG·LK, 1~10. 장비·약물·상태로도 표시값은 1~10.
- 시작 기본 5씩(35) + 추가 5 = 40. 깎아서 재배분 가능.
- 영구 상승이 10 초과 시 **내부값 계속 기록**, 감소는 내부값에서 빼고 표시는 1~10으로 자름.
- 레벨업으로 직접 오르지 않음(인텐스 트레이닝·흔들인형·퀘스트로만).
- **퍽 요구 판정 = 영구값(기저값)**. 예외: 미수령 복권(M-321)만 반영.
- **능력치 체크 판정 = 현재값(일시 보정 포함)**.
- 레벨업 스킬 포인트 = 레벨업 순간 영구 지능(소급 없음).

### 7.4 **구현 정합(단계 0-9 볼트 S-07)** (L1038~L1043, 이미 게임에 반영)
