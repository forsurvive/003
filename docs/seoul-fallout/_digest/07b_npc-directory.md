## 2. 표기 규칙 (L61, §4 표의 13열)
- 열: `ID | 이름 | 성·나이 | 종 | 세력 | 장소 | 역할 | 서비스 | 일과(낮/밤) | 외형 코드(통일안) | 원래 코드와 다른 칸 | 관련 퀘스트 | 출처`.
- **ID**: 주요 인물 `C-ID · 주 N-ID`(결번은 괄호). 일반 NPC는 N-ID. **501 이상 = 07b 신규**.
- **이름**: 정본. 별명·호출 부호·신앙 번호는 괄호 안 작은따옴표. `←` = 개명 전 옛 이름.
- **성·나이**: 2277 기준. 주요 인물은 07a 정확 나이, 일반 NPC는 나이대. 구울은 2077 나이 병기.
- **종 약어**: 인 인간 / 구 구울 / 빛구 빛나는 구울 / 야구 야생화 직전 구울 / 변 변종 / 로 로봇 / 개 / 기록.
- **세력**: SD-06 §2.2 약호. 정착지 연합은 `JC·정착지 약호` — **BC 봉천, TK 탱크마을, ND 노들섬, SY 선유도, TS 뚝섬, SV 세이프빌, SA 사당, MW 망원, IT 이태원, YJ 양재, AC 아차산, CD 창동**. `—` = 소속 없음. 그 밖 약호(§2.5): MS 무소속 주민, BJ, YH, YT 약탈자, S7 볼트 S-07, JH, SB, GS, JG, HS 한강 행상 조합, CB 철벽경호, NS 남산 방송, WP, NJ 난지 고철단, KD 큰돌 무리, JY 자율방범대, DG 순회 의료반 들것, BY 변종.
- **장소**: 주 거주 L-ID(`L-` 생략: `R01-09` = L-R01-09). 순회는 정류 장소.
- **서비스 약자**: 상 상인 / 의 의사 / 수 수리·정비 / 정 정보 / 숙 숙박 / 통 통행 / 지 지원 병력 / 동 일시 동행 / 교 교습·비기. 뒤 V번호 = SD-15 상인 번호.
- **원래 코드와 다른 칸**: `원래 → 통일안`. `=` 동일, `신규` = 07b가 처음 지은 코드. 원래 문서가 둘 이상이고 다르면 다른 쪽 문서를 앞에(예 `09a HR03→06`). **통일안 값이 정본**. `W` = 낡음 칸. 접두어 생략(`HD12→04`).
- **관련 퀘스트**: 최대 5개. `+JH-04` = SD-04d 세력 퀘스트 블록 FQ-JH-04에 이름이 나옴. **출처**: 행을 만든 문서.

## 4. 외형 코드 통일안 (L199~L345) — **번호 뜻의 정본**
### 4.1 원칙·문제(L201)
- 형식(SD-16 §7.2) `몸-피부-머리-머리색-몸통계열-낡음-팔레트-머리장비-눈장비-소품`. SD-16은 수량만 정함(몸 6벌, 머리 12, 머리 장비 18, 눈 장비 8, 소품 목표 200) → 07b가 번호 뜻을 붙임.
- 통일 전 문제: ① 몸: 09a·07a `E1·E2`, 09b·09c `E1`(공용), 09d·09e `OL`·`CH`, 09f `O1` ② 머리: 09b·09d·09e·07a가 HR12~17 사용 ③ 낡음: 09a~c·07a 0~2, 09d~f 1~3 ④ HD·EY 번호 뜻이 문서마다 다름(예 HD11 = 07a 선원 모자 / 09b 농부 모자 / 09e 오토바이 헬멧) ⑤ 소품: 09a PR001~050(뜻 있음), 07a PR701~718, 09b·09d·09e PR0xx·1xx(뜻 없음), 09c PR5xx·6xx, 09f PR160~263.
- 통일 방법: ① 뜻 적힌 번호(09a·07a) 기준 ② 뜻 없는 번호는 쓰임새(역할·세력)로 추론해 옮김 ③ 소품은 **역할 추론 + 같은 장소 안 중복 금지**로 재배정 ④ 원래 값은 §4 표 '원래 코드와 다른 칸'에 보존.
- 결과: 인간형 688명 중 칸별 변경 — 소품 526, 낡음 287, 머리 장비 199, 머리 105, 눈 장비 100, 몸 47. **같은 장소 안 같은 코드 0건, 같은 소품 0건**(SD-16 §7.2 충족).
