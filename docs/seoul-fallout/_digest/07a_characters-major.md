> 원문: `docs/seoul-fallout/07a_characters-major.md` · SD-07a · v1.2 · 2026-10-12 · 1649줄. `Lnnn` = 원문 줄. 원문에 '구현 정합(단계 0-x)' 블록 없음.

## 0. 머리 (L1~L5, L25~L45)
- **다룸**: 주요 인물 C-001~C-075(선정 기준·ID·관계도·프로필·생사/대체·초상 등급·voice_type), S-07 관리 계보·오버시어 계보, MQ별 등장 인물, 이름·설정 충돌 정본 제안.
- **안 다룸**: 일반 NPC(N-권역-번호 → SD-07b·09a~f), 퀘스트 분기(03a·03b·04a~d), 세력 수치(06), 전투 수치(14), 초상 도트 규격(16), 블립 음색(17).
- **정본 관계(L32)**: 07a = 인물 설정 정본(프로필·C-ID·초상 등급·voice_type·생사·대체). 07b = 일반 NPC + **외형 코드 번호 뜻(§3 통일안)**, 07a 인물의 부하·가족·직원 이름도 07b가 짓는다. 장소 문서 N-ID와 겹치면 **C-ID 정본**(N-ID는 장소 등록 번호로만). MQ 역할·생사 변수는 03a·03b 값을 옮김 → **다르면 03a·03b 정본**. 세력 수치·반응 = 06, CR 수치 = 14. **보스 이름 확정 = 07a**(SD-14 §10.2 요청). 인물별 외형 코드 값·voice_type = 07a(SD-16 §8.4, SD-17 §6.2 요청).
- **요약 결정(L38)**: 75명 = 바이블 §11 21(핵심 3·주요 11·이름 있는 NPC 7) + 볼트 9(기록 3 포함) + 세력 간부 27 + 세력 2077 기록 2 + 정착지·중립 8 + 보스 7 + 특수 1.
  - **'고르지 않고 기운다'**: 어떤 인물도 "우리 편이 되겠나?"를 묻지 않는다. 행동 결과가 호칭·인사·가격·순찰·방송으로 돌아온다(바이블 §5.8).
  - **동료 없음**(바이블 K7). v0.2 동료 후보 7명 → 이름 있는 NPC C-015~021, 구간 일시 동행·동맹 지원 병력 지휘자(SD-06 §8)만.
  - 이름 교체: 강태오→**육지환**, 천웨이→**멍쉐밍**, 국민방송→**공보방송**(2077 = **전시 국영방송**), '불구'→**부위 손상**. 한결건설 마스코트 **든든이**, 원칙파 약호 **WP**.

## 2. 표기 규칙 (L47~L70)
- 데이터 키 `chr_` + 로마자 성_이름(SD-18 §9.5). 중국 인명 병음, 별명 로마자 뜻. 주인공 = `pc`(C-ID 없음).
- 나이 = **2277 게임 시작 시점**. 구울은 2077 나이·생년 병기. 종: 인간/구울/야생화 직전 구울/변종/로봇/개.
- 분류: K 핵심 / A 주요 / N 이름 있는 NPC / V 볼트 / S 세력 간부 / L 정착지·중립 / B 보스 / R 기록 / X 특수.
- 생사: 불사(구간) / 살해 가능(대체 있음) / 살해 가능(대체 없음 = 기능 소멸, 메인은 안 막힘) / 살해 불가(아동) / 기록.
- 초상: **A** 고유·표정 6 / **B** 모듈+고유 특징 손보정·표정 3 / **R** 기록 1장(흑백 회상 필터) / **–** 없음.
- 외형 코드(SD-16 §7.2) `몸-피부-머리-머리색-몸통-낡음-팔레트-머리장비-눈장비-소품`. 몸: M1 남 표준/M2 남 변형/F1 여 표준/F2 여 변형/E1 노인 남/E2 노인 여/K1 아동, 변종 `BY`, 로봇 `RB`. 번호 뜻 정본 = SD-07b §3.
- voice_type = SE-TXT-01~11 + 피치(±반음). 말씨 = SD-12 §6.5 '주인공 말씨'(하십시오체/해요체/해체).
- **인물 카르마(SD-10 §6.3)**: 매우 악 처치 **+100**, 악 **0**, 중립 이상 처치 **-100**.
- 태도 변화 = 호감도 6단계(적대·경계·중립·우호·신뢰·동맹)·판도에 따른 세계 반응. **숫자로 알리지 않는다**(바이블 §6.2).
- **대사 원칙(금지)**: ① 진영을 묻지 않는다("어느 편이냐", "우리와 함께하겠나", "이 제안을 받아들이겠나" 금지) ② 선택지는 개별 사안(값·진실·생사·물건 행방), 대화 1회로 호감도 크게 안 바뀜(SD-12 §6.3) ③ 말투는 출신: 2077 구울 = 2077 표준어·공문 습관, 2277 황무지 = 짧은 구어, 연합단 = 한국어+영어 군사 용어, 비상정부 = 공문체·하십시오체, 각성회 = 관제망 안내 방송투, 잔존병 = 침투 교육식 정확·딱딱한 한국어 ④ **잔존병 억양 흉내·틀린 한국어 희화화 금지. 각성회에 신·기도·성직·경전·성가 형식 금지**(SD-06 §10.11) ⑤ 2077 = '전시 국영방송', 2277 비상정부 = '공보방송'.

## 3. 인물 체계 (L74~L153)
- **기준(L76)**, 하나 이상 + 대화 상호작용(또는 기록으로 메인 진행에 직접 쓰임): ① 메인 핵심 기능(MQ 필수 구간, 생사 변수 `D_*`·`V_MOTHER`·`V_DOYUN`·`V_NAMGUNG`·`V_YUK`·`V_MXM`, SD-03a §6.3 대체자) 약 45 ② 세력 지도자·간부(SD-06 10세력 수장·2인자·분파 수장, 철벽경호·자율방범대 수장, 핵심 정착지 6곳 봉천·탱크마을·노들섬·선유도·뚝섬 장터·세이프빌 대표) 약 38 ③ 고유 초상(SD-16 §8.2) 40 ④ 보스(SD-14 §10.2 이름 있는 인간·구울·변종 + §10.4) 23. 기준 밖 상인·주민·부하는 SD-07b. 기록 인물 C-ID는 메인 판정에 쓰이는 6명만(한유리·한유정·하준기·장문석·도정훈·서니 델가도). 사이드 핵심 인물은 **C-076~099 예비**.
- **C-ID 대역(L90)**: 001~003 핵심 / 004~014 주요 / 015~021 이름 있는 NPC / 022~030 볼트 / 031~037 비상정부 F-01 / 038~045 연합단 F-02 / 046~048 원칙파 F-03 / 049 새벽인력 F-05 / 050~052 지하시장 F-10 / 053 각성회 F-11 / 054~056 잔존병 F-08 / 057~062 정착지 연합 F-12 / 063~065 카르마 추적자(F-06 철벽경호, F-07 자율방범대) / 066~067 중립(F-17 한강 행상 조합, F-18 순회 의료반 들것) / 068~074 보스(F-04 약탈자, F-09 변종, 당인리 구울) / 075 특수 / 076~099 예비. 세력 순은 SD-06 §2.1, 단 바이블 §11 인물은 앞 대역(예: 황두칠 C-013).
- **생사·동행(L115)**
  - **프롤로그 불사**: MQ-P1~P4에서 윤정인·하도윤·육지환·도경철은 **체력 1에서 '무릎 꿇음'**(SD-03a §6.4). 차명수·방금례·신혜령·나채윤·지우는 프롤로그에서 **공격 판정 없음**.
  - **볼트 밖 불사 인물 없음**(SD-03a §6.3). 예외: 아동(살해 불가), **구간 불사** = 조만석(MQ-101 방어 구간, 이장실에서 안 나옴), 윤석진(MQ-106 철수), 육지환(MQ-106 비교전), 백구(MQ-101 S1).
  - **일시 동행 NPC**: 쓰러지면 기본 **'부상 퇴장'**(사망 아님). '사망 가능' 구간만 사망(SD-03a §5.5): 백구 MQ-101, 박춘삼 MQ-103, 제이슨 임 MQ-205~206, 샤오린 MQ-303.
  - 기록 인물: 살해·대화 불가. 터미널·홀로테이프·사진·콘솔로만.
- **인원 집계(L121)**: K 3(A3) / A 11(A11, 한유리 회상판) / N 7(A7; 백구 스프라이트 감정, 파수-3 CRT) / V 9(A3·B3·R3) / S 27(A11·B16) / R 세력 기록 2(R1 도정훈, 없음 1 서니 = 화자 아이콘) / L 8(A5·B3) / B 7(B7) / X 1(B1) → **합계 75 = A40·B30·R4·없음1**. S 27 = C-031~036, 038~044, 046~056, 063~065. `S·B` 겸직 = 로건 백·구학수·은솔·왕융성·류강민·오순례. 분류 정본 = 3장 표.
