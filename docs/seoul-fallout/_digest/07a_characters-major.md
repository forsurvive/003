# [digest] SD-07a 주요 인물

> 원문: `docs/seoul-fallout/07a_characters-major.md` · 문서 ID SD-07a · v1.2 · 2026-10-12 · 1649줄. 줄 번호 `Lnnn`은 원문 기준.

## 0. 머리 (L1~L5)
- **다룸**: 주요 인물 C-001~C-075의 선정 기준·ID 체계, 전체 인물 표, 관계도(메인 축·세력 지도부·볼트 S-07), 인물별 프로필(나이·성별·종, 소속·직함, 장소, 외형·외형 코드, 성격·말투·대사, 배경 2077→2277, 목표·두려움, MQ 역할, 호감도·판도별 태도, 생사·대체, 결말 슬라이드, 전투 참조, 서비스), S-07 관리 계보·오버시어 계보, MQ별 등장 인물, 이름·설정 충돌 검사와 정본 제안.
- **다루지 않음**: 일반 NPC(N-권역-번호 → SD-07b·SD-09a~f), 퀘스트 진행·분기(SD-03a·03b·04a~d), 세력 수치(SD-06), 전투 수치 본문(SD-14), 초상화 도트 규격(SD-16), 블립 음색(SD-17).
- **정본 관계(L32~L36)**
  - 이 문서 = **인물 설정의 정본**(프로필, C-ID, 초상 등급, voice_type, 생사·대체 규칙).
  - SD-07b = 일반 NPC와 **외형 코드표 전체**. 07a 인물의 부하·가족·직원 이름은 07b가 짓는다.
  - SD-09a~f가 주요 인물에 N-ID를 먼저 준 경우 **C-ID가 정본**, N-ID는 장소 등록 번호로만 남는다(부록 C).
  - MQ 역할·생사 변수는 SD-03a·03b 값을 옮김 → 다르면 **03a·03b가 정본**. 세력 수치·반응표 = SD-06. 전투 수치(CR-ID) = SD-14. **보스 이름 확정은 이 문서**(SD-14 §10.2 요청). 인물별 외형 코드 값·voice_type = 이 문서(SD-16 §8.4, SD-17 §6.2 요청).

## 2. 표기 규칙·대사 원칙 (L47~L70)
- **데이터 키**: `chr_` + 로마자 성_이름(SD-18 §9.5). 중국 인명은 한어 병음, 별명은 로마자 뜻.
- **나이**: 2277년 게임 시작 시점. 구울은 2077년 나이·생년 병기. 종: 인간/구울/야생화 직전 구울/변종/로봇/개.
- **분류**: K 핵심 / A 주요 / N 이름 있는 NPC / V 볼트 S-07 / S 세력 간부 / L 정착지·중립 대표 / B 보스 / R 기록 / X 특수.
- **생사**: 불사(구간) / 살해 가능(대체 있음) / 살해 가능(대체 없음: 기능 소멸, 메인 진행은 안 막힘) / 살해 불가(아동) / 기록.
- **초상 등급**: A 고유·표정 6 / B 모듈+고유 특징 손보정·표정 3 / R 기록 초상 1장(흑백 회상 필터) / – 없음.
- **외형 코드**(SD-16 §7.2): `몸-피부-머리-머리색-몸통계열-낡음-팔레트-머리장비-눈장비-소품`. 몸: M1 남 표준/M2 남 변형/F1 여 표준/F2 여 변형/E1 노인 남/E2 노인 여/K1 아동, 변종 `BY`, 로봇 `RB`. 번호 뜻 정본 = **SD-07b §3 통일안**. 07a 소품 대역 `PR701~718` → 통일안 `PR051~068`.
- **voice_type**: SD-17 §6.2 SE-TXT-01~11 + 피치 오프셋(±반음). **말씨**: SD-12 §6.5 '주인공 말씨' 필드(하십시오체/해요체/해체), 전환 시점 병기.
- **인물 카르마**(SD-10 §6.3): 매우 선/선/중립/악/매우 악. **매우 악 처치 +100, 악 0, 중립 이상 처치 -100**('악하지 않은 인물 살해').
- **태도 변화**: 호감도 단계(적대·경계·중립·우호·신뢰·동맹)·판도에 따른 세계 반응(호칭·인사·가격·순찰·방송·물건). **숫자로 알리지 않는다**(바이블 §6.2).
- 다른 문서 소관 새 ID 필요 시 `(SD-xx에서 ID 부여)`.
- **대사 작성 원칙**(금지 포함)
  1. 진영을 묻지 않는다: "어느 편이냐", "우리와 함께하겠나", "이 제안을 받아들이겠나" 금지(바이블 §5.8). 인물은 바람·부탁·사실 진술만.
  2. 선택지는 개별 사안(값·진실·생사·물건 행방). 대화 한 번으로 호감도 크게 안 바뀜(SD-12 §6.3).
  3. 말투는 출신이 정한다: 2077 구울 = 2077 표준어·공문 습관 / 2277 황무지 = 짧은 구어 / 연합단 = 한국어+영어 군사 용어 / 비상정부 = 공문체·하십시오체 / 각성회 = 관제망 안내 방송투 / 잔존병 = 침투 교육으로 배운 정확·딱딱한 한국어.
  4. 잔존병 말투를 억양 흉내·틀린 한국어로 희화화 금지. 각성회 어휘에 신·기도·성직·경전·성가 형식 금지(SD-06 §10.11).
  5. 2077 국영 방송 = '전시 국영방송', 2277 비상정부 방송 = '공보방송'.

## 3. 요약 결정 (L38~L45)
- 75명 구성: 바이블 §11 21명(핵심 3, 주요 11, 이름 있는 NPC 7) + 볼트 9(기록 3 포함) + 세력 지도부·간부 27 + 세력 2077 기록 2 + 정착지·중립 8 + 보스 7 + 특수 1.
- **고르지 않고 기운다**: 어떤 인물도 "우리 편이 되겠나?"를 묻지 않는다. 주인공의 실제 행동이 호칭·인사·가격·순찰·방송으로 돌아온다(바이블 §5.8).
- **동료 없음**(바이블 K7). v0.2 동료 후보 7명(백구, 큰돌, 제이슨 임, 박춘삼, 파수-3, 진세라, 독사)은 이름 있는 NPC(C-015~021). 정해진 퀘스트 구간 일시 동행만, 일부는 '동맹' 지원 병력 지휘자(SD-06 §8).
- **이름 교체**: 강태오 → 육지환(C-004), 천웨이 → 멍쉐밍(C-007), 국민방송 → 공보방송(2077 = 전시 국영방송), '불구' → '부위 손상'. 한결건설 마스코트 = **든든이**, 원칙파 약호 = **WP**.
- 이름 충돌 정리: SD-14 '선우진(각성회 개통파)' → **은솔**, '홍순례' → **오순례**. 배기통=버스왕 방석구, 방열복=관제탑 차보람(본명+별명+통칭 한 사람). 남부순환 두목 = 삽자루, 깡철이 = 부두목. '루카스 문' → **펠릭스 문**.
- 초상: A 40명 × 표정 6 ≈ 248컷, B 30명 × 3 = 90, R 4 + 오버시어 액자 1. 합계 ≈ 345컷.

### 4.3 생사·일시 동행 규칙(L115)
- **프롤로그 불사**: 볼트 안(MQ-P1~P4)에서 윤정인·하도윤·육지환·도경철은 체력 1에서 '무릎 꿇음'으로 멈춤(SD-03a §6.4). 차명수·방금례·신혜령·나채윤·지우는 프롤로그에서 **공격 판정 없음**.
- **볼트 밖에는 불사 인물 없음**(SD-03a §6.3). 예외: 아동(지우 등, 살해 불가)과 **구간 불사**: 조만석(MQ-101 방어 구간, 이장실에서 안 나옴), 윤석진(MQ-106 철수), 육지환(MQ-106 비교전), 백구(MQ-101 S1 장면).
- **일시 동행 NPC**는 쓰러지면 기본 '부상 퇴장'(사망 아님). '사망 가능' 표시 구간만 사망(SD-03a §5.5): 백구(MQ-101), 박춘삼(MQ-103), 제이슨 임(MQ-205~206), 샤오린(MQ-303).
- **기록 인물**: 죽일 수 없음, 대화 없음. 터미널·홀로테이프·사진·콘솔 메시지로만.

## 25. 미정·충돌·모순으로 보이는 곳
- **L1275** C-065 오순례 역할 칸: "SD-14·SD-13의 '오순례'는 오순례로 바꾼다" — '홍순례'의 오기로 보임(부록 A A-02와 대조).
- **L468** C-002 결말 슬라이드 "ES-05, ES-31 대신 MQ-E1 후일담 '2순위'" — ES-05를 쓰는지 표현이 모호.
- **L633 vs L1503** 다니엘 서 말씨 전환 조건: 프로필은 'YH 우호 이상', 9.6은 'YH 신뢰'. 한편 태도표(L664)에서 "같이 갑시다"는 신뢰 단계 대사.
- **L1465 vs L1511** N2 대상: "A 40명 중 백구·파수-3·한유리 뺀 37명 + 큰돌" — 큰돌은 이미 A(37명에 포함)라 '+ 큰돌'이 중복처럼 읽힘. 9.7은 N2 전용 파츠 38명.
- **L1473~L1476** 9.3 voice 배정표는 전원 망라가 아님: 쥐왕(SE-TXT-01 −3, 인간 남 표에 −3 칸 없음), 맹구철(−2), 토마스 백(−2), 헨리 오(0), 차민혁(0), 기세훈(−1), 곽재민(0), 류강민(−1), 방석구(0)는 프로필에만 있음.
- **L413** 윤정인 성격 서술 "볼트 190명" vs 6장(L1309) 2277 인구 192명(6장은 '약 190'과 같은 값으로 본다고 명시).
- **L1456** A 초상 248 산식: 37명×6에 특수 형식 3명(한유리 2, 백구 4프레임, 파수-3 CRT 6)을 어떻게 더했는지 원문에 따로 없음.
- **L1412~L1413 vs L1513** 7.2 대체 표는 15행(대체자 없는 3행 포함)인데 대체자 대사 묶음은 14벌로 적힘 — 원문만으로 대응 관계 불명.
- **L1592·L1248·L1284·L1290** CR-ID 미부여: 허문경, 탕밍, 맹구철, 무쇠는 '(SD-14에서 ID 부여)'. 낯선 이 리볼버는 SD-13에서 ID 부여, 등장 효과음은 SD-17이 정함.
- **L1557** A-18: 양재 온실촌 권역 R07 → R11 정정(N-14).
