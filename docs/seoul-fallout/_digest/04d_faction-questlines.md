## 0. 머리
- **범위**: 호감도 대상 10세력(BJ 비상정부, YH 연합단, WP 원칙파, SB 새벽인력, JG 중국군 잔존병, JH 지하시장, GS 각성회, JC 정착지 연합, NJ 난지 고철단, KD 큰돌 무리)의 **세력 퀘스트 69편(FQ-BJ-01~FQ-KD-05) 상세 설계**. 라인별 주제·단계 배치·메인 막 연동·라인 끝 결과·흐름도, 퀘스트별 발동·제공자·장소·로그·해법·결과 분기·호감도(직접·연동)·판도·카르마·XP·보상(아이템 ID)·전파·실패·대사·연계, 충돌 지점('누구에게 실제로 넘기는가'), 세력 간 교차표, 속죄 의뢰와 화해.
- **다루지 않음**: 호감도·판도·정보 전파 시스템 본체(SD-06), 메인 진행(SD-03a·03b), 사이드(SD-04a~c), 반복·비표시·랜덤 인카운터 ID(SD-05), 인물 프로필·C/N-ID(SD-07a·07b), 장소 상세·좌표 보정(SD-09a~f), 아이템·적 수치(SD-13·14).

## 2. 개요 핵심 (L32~)
- 목적: SD-06 §13의 **69편 골격**(제목·요지·시작 단계·호감도 보상)을 이벤트·변수 단위로 상세화. **ID·번호·순서 그대로**, 바꾼 곳은 '변경 사유'. 바이블 §5.8 "고르지 않고 기운다": 가입 절차가 아니라 부탁을 실제로 들어준 결과가 쌓여 그 세력이 계급장·비기를 **먼저 건넨다**. 경쟁 세력은 소문·방송·목격자로 알고 반응. 메인 경로 퀘스트·3막 열쇠 현장·5막 위기 퀘스트와의 겹침을 정해 **어느 순서로 해도 막히지 않게**.
- 요약 7항(L52):
  1. 69편 = BJ 8, YH 8, WP 6, SB 6, JG 7, JH 7, GS 7, JC 10, NJ 5, KD 5. 골격 수정 7편(§1.5).
  2. **묻지 않고 시작**: 게시판·부탁·엿듣기·다음 단계(·우연). 로그(핍-보이 '부탁받은 일')는 모두 사실·상황 문장. "누구 편에 서겠습니까", "의뢰를 받아들이겠습니까" 없음.
  3. **결과는 손에서**: 실제로 건넨 상대·살린 사람·두고 떠난 곳. **충돌 지점 14곳**, 인도처 변수 `FH_`로 기록 → 전파(§14).
  4. **라인 끝 = 동맹 문턱(+80)** 근처로 배분(연합단 0 → +83, 각성회 +25 → +94). 시작값 낮은 세력(BJ -30, JG -40, NJ -70)은 메인 결정적 행동이 더해져야 동맹(또는 신뢰 상한). 마지막 편 후 비기(PK-112~119) 장면.
  5. **세계가 먼저 알려 준다**: 호칭·가격·순찰·방송·깃발로 '기울기 체감'. **숫자 팝업 없음**.
  6. **막 잠금 없음**: 프롤로그 직후부터 모두 열 수 있음. 막은 일부 편의 '사건 조건'(당인리 재가동, 회의 결렬, 계엄 선포 등)으로만.
  7. XP 편당 250~550, 마지막 편 ×1.5(SD-10 §4.4). **전체 29,900 XP**. 증표·호출·장비는 SD-13 §5.10 ID로 지급 시점.

### 2.1 표기 (L61)
- `FQ-BJ-01` → 엔진 변수 `FQ_BJ_01`(0 미발동 / 10 발동 / 20~90 진행 / 100 종료 / 200 보류 / 250 끊김), 결과 `FQR_BJ_01`.

### 3.2 발동 (L105)
- 5방식: 게시판(호감 단계 맞을 때만, 예 용산 PX 게시판 FQ-YH-01) / 부탁(선택지 "자세히 듣는다 / 나중에"뿐, "나중에"도 로그에 '들은 사정', 예 FQ-JH-02) / 엿듣기(대화·쪽지·무전, 예 FQ-SB-03) / 다음 단계(예 당인리 재가동 → FQ-JG-05) / 우연(예 버티버드 추락 FQ-BJ-03).
- 알림 = 토스트 아님, **로그 한 줄 + 효과음 1종**(SD-12). 지도 마커는 '알려진 단서'에만(SD-03a §3.3 F2).
- **같은 세력 다음 편은 앞 편 종료 후 게임 시간 12시간 뒤**부터. 메인 사건으로 열리는 편은 예외.

### 3.3 단계 조건·진행 중 변화 (L117)
- 발동 단계 미달: 게시판·인물 안 꺼냄. 엿듣기·우연형은 사건은 보여 주고 로그 "○○는 아직 당신에게 이 일을 맡기지 않는다".
