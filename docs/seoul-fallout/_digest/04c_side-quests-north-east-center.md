## 0. 머리
- **범위**: 지도 표시 사이드 퀘스트 **27편 SQ-N01~N27**. 권역 R05 도심(밀폐)·R06 용산·남산·R08 동부·R09 북부 산악·UG 지하(이 문서 담당 훅만). 퀘스트마다 발동·인물·로그·진행·다중 해법·결과·카르마·호감도·판도·정보 전파·보상·실패·대사·연출·연계.
- **이 문서가 맡는 지정 항목**: 6막 도심 전용 퀘스트(N05·N06), 관제 본부 출입 권한 M-240~242의 사이드 대체 경로, 뚝섬 장터 거처 퀘스트(N13), PK-110 '생존 수첩' 퀘스트(N11).
- **다루지 않음**: 메인 본문(SD-03a·03b), 세력 FQ(SD-04d), 비표시·반복·랜덤 인카운터(SD-05), R01·R02·R07·R11(SD-04a), R03·R04·R10·한강(SD-04b). 09f가 넘긴 한강 훅 HR-H07~09·12는 범위 밖(§13 N-01로 해소).
- **정본 관계**: XP SD-10 §4.4 / 판정 단계 SD-10 §3.5·§3.6(I~V = 15/25/50/75/100) / 호감도 기본값 SD-06 §3.4, 연동 계수 §3.6 / 판도 SD-06 §5.2 / 공개도 SD-06 §6.2 / 세력 코드 SD-03a §4.5 + RECON_SPEC §3.1 확장 코드 / 아이템 등록 SD-13 / 기록물 SD-02 §10 / 로그 문체 SD-12, SD-04d §2.1 R2. 결말 슬라이드 최종 문안 SD-03b §7. **방석구(CR-510) 보스전 정본 = 이 문서 SQ-N17**. 세트 정합 기준 RECON_SPEC.
- 관련 문서: SC-00 §5.3~5.8·§6.2·§11, SD-02, 03a §4·5·6, 03b §4·5·7, 04a, 04b, 04d, 05, 06 §3~7·§13, 07a, 07b, 09c, 09e, 09f, 10 §3.6·4.4·5.4·6.3, 13, 14, 15 §7, 18, 원작 RD-05·06·27.

## 4. 표기·공통 규칙
### 4.1 표기 (L60)
- `SQ_Nxx` 단계: 0 미발동 / 10 발동 / 20~90 진행 / 100 종료 / 200 보류 / 250 끊김. 결과 `SQR_Nxx`.
- `SQH_<물건>` 인도처 코드(SD-03a §4.5): 0 주인공 / 1 BJ / 2 YH / 3 WP / 4 JH / 5 GS / 6 JG / 7 SB / 8 JC / 9 NJ / 10 KD / 14 남산 방송 / 81~86 개별 정착지 / 97 두고 떠남 / 99 파기. 확장(RECON §3.1): **94 SW 세운 공방, 17 JY 자율방범대, 89 IT 이태원 피난촌, 90 AC 아차산 배수지 마을, 91 CD 창동 차량기지촌, 21 남대문 보급소(장소 보관), 19 BY 서울역 무리(무쇠)**.
- 로그 = 핍-보이 문장(SD-12), 사실·상황·소문만. 판정 [화술·보통]/[과학 50]/[힘 7]. `TS +8` = 직접 호감도(보정 전), 정착지 개별 `AFF_JC_<약호>`, '연합 일괄 +N'. **연동** = SD-06 §3.6 계수, 알게 된 때 적용. 판도 'PD-R08-6 YT -30'. 공개도 0 비밀/1 목격/2 공개/3 방송급. 기록물 LR-68~74·LR-85·LR-96(SD-02 §10 등록).

### 4.2 고르지 않고 기운다 (L78) — SD-04d R1~R7 + 3
- **S1 의뢰인을 고르지 않는다**: "누구에게 주겠습니까?" 메뉴 없음. '물건 주기'·장소 보관함·들고 떠남이 결과(N01·N04·N07·N11·N16).
- **S2 대화는 개별 사안만**: 서식 등급 칸(N05), 연극 마지막 줄(N03), 후손에게 말할 범위(N22). 진영을 정하지 않음.
- **S3 사람의 자리를 바꾼다**: 결과마다 세계가 먼저 알려 주는 변화 1개 이상(장터·궤도차·신호등·낭독 목록·깃발).

### 4.3 발동·막 (L87)
- 발동 5방식(SD-04d §2.2: 게시판·부탁·엿듣기·다음 단계·우연). 로그 첫 줄은 상황 문장.
- **막 잠금 없음**. 위협도만 막음. 6막 전용 N05·N06은 G3 '사대문 봉쇄'(`V_ENTRY ≠ 0`) 후 발동.
- R05는 6막 전 진입 가능(SD-03a O-08): G7 세운 하수로 왕복(국건우, 50캡), G8 남산 대피 터널, G1 1호선, G2·G3 충정로·독립문.

### 4.7 6막 도심 퀘스트 vs MQ-605 (L122)

### 4.8 묘사 원칙 (L140)
- 중국군 잔존병: 명령에 갇힌 병사. 교범식 한국어, 서툰 병사는 `[중국어] 번역문`. 억양 흉내·외모 조롱 금지. 반중 선전물은 배경만. **자결 해법 없음**. 멍쉐밍 상위가 최상위 판단자.
- 이태원 피난촌: 이태원로 동쪽 언덕·옛 시장 골목. 실제 참사 골목은 '천막 창고 뒤 막힌 길'로 두고 **전투·사망·군중 장면 금지**(N09·N11은 언덕 위·남산 남사면에서만).
- 북방 병합지·월경 피란민: 현실 북한 정권으로 그리지 않음. 2076년 피란민 = '국경을 넘어온 사람들'. N22는 2077년 '국경 이탈자 = 적성 분자' 낙인을 다룸.
- 변종: '사람이었던 것'의 흔적(무쇠의 접수, 소화전의 편지). 큰돌 무리는 이웃. 구울: 2077 직함·말투. 야생 구울 '환자'(N03)는 존엄 쪽 연출. 설화·민속·신앙·귀신 소재 **쓰지 않음**.
