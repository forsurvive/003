### 1.4 표기·단위 (L73~L80)
- 1t = 타일 한 칸 = 32×32px(SD-16) ≈ 실제 1m. 내부 해상도 640×360 → 화면 가로 20t × 세로 약 11t(와이드 폰·태블릿 최대 약 27t×15t, §15.6).
- 사람 충돌 원 지름 약 0.6t.
- 시간 배율: 실시간 1초 = 게임 시간 30초(SD-12 확정).
- `스킬`=무기 지배 스킬(0~100), `⌈x⌉` 올림, `clamp(a,x,b)`.
- 퍽은 원작 이름으로 적음(서울판 이름·PK-ID는 SD-10). 무기·적은 계열+대표 원형으로(W-/A-/CR- ID는 SD-13/14). 용어는 RD-26.

## 3. 전투 개요 (§2)
### 2.1 (L86~L91)

### 4.1 탄 퍼짐 (L336~)

  - 스킬 항: 0→12°, 25→9°, 50→6°, 75→3°, 100→0°
  - 자세: 서기 1.0 / 웅크림 0.7 / 정조준 0.5 / 웅크림+정조준 0.35 / 중화기 정조준 0.75 / 저격 안정 추가 ×0.5

### 4.3 명중 판정 (L384~L390)

- 넉다운 대상: 반지름 ×1.3, 다리 가중치 0.

### 4.4 피해 순서 (L392~L414)
Dmg(+고정 가산 퍽) → 스킬 계수 (100+스킬)/200 → 상태 계수 → 파워 ×2 → 힘/비무장 보너스 가산·팔 손상 감산 → 거리 감쇠 → 피해 퍽·약물 배수 → 치명타 굴림(기습 확정) → 치명타 피해 가산 → 기습 배수(원거리 2, 근접·비무장 5, 보스 상한 2) → 부위 판정 → 부위 배수(머리 2 등) → DR(상한 85) → 막기 감쇄 → 난이도 배수 → 최종(HP·부위 체력 차감, 경직·넉다운 판정).

## 6. AP (§5)
### 5.1 결정 (L600~L607)
- AP = 실시간 행동 자원: 질주, 회피 구르기, 집중 사격, 근접 파워 공격(파워 아머 착용 시 돌진).
- 기각: '삭제'(민첩성·AP 퍽·약물 무의미), '조준 사격 전용'(회피 수단 없음), '달리기·회피 전용'(무기 정체성 상실).
- **일반 사격·일반 근접에는 AP를 쓰지 않는다**(원작 개발 기록 문제 회피).
### 5.2 수치 (L609~L618)
```

AP 0 = 질주 자동 종료, 회피·집중 사격·파워 공격 불가, '숨참' 표시
```

## 7. V.A.T.S. 축약형 (§6, 선택 과제)

### 7.1 구조 (L742~L763) — 원작 3D 엄폐·측면 AI를 규칙형으로 단순화(X7), '살아 있는 적'(도주·항복·광란·무리·세력 간 싸움, E19)은 유지

### 7.3 인지 (L818~L866)
```
시야 거리 = 8 + 0.6×인지력 (3→9.8t, 5→11t, 8→12.8t, 10→14t)

시선 차단: 높은 엄폐·벽·닫힌 문; 낮은 엄폐는 웅크린 대상만
게이지(관찰자×표적, 0~100) 초당 증가 = 120 × 거리 × 자세 × 조명 × 움직임 × 은신 × 인지 × 상태
  거리 = max(0.1, 1 − (거리/시야 거리)^1.5)
  자세 = 서기 1.0 / 웅크림 0.5
  조명 = 밝음 1.0 / 어두움(실내 소등·야간 외부) 0.6 / 칠흑 0.35; 핍-보이 조명 켜면 1.0 고정
  움직임 = 정지 0.5 / 웅크림 이동 0.8 / 이동 1.0 / 질주 1.5 / 사격 직후 1초 2.0
  은신 = 웅크림일 때만 1 − 은신/150 (100→0.33), 스텔스 보이류 0.1
  인지 = 0.6 + 0.08×관찰자 인지력 (5→1.0)
  상태 = 의심·수색 중 1.5 / 머리 손상 0.6

```

## 9. 아군 NPC·대규모 교전·호감도 (§8)
### 8.1 원칙 (L1011~L1019, 바이블 v0.3 K7)
- **동료 시스템 없음**: 영입·동료 인벤토리·명령·동료 퍽·동료 결말 슬라이드 만들지 않음. 아군 AI는 §7 AI에 '아군' 플래그.
- 3종: 일시 동행 NPC(하도윤, 백구, 큰돌, 제이슨 임, 박춘삼, 파수-3, 진세라, 독사 등, 바이블 §11; 퀘스트가 붙여 줄 때만, 대화로 따라와/기다려만) / 세력 지원 병력(신뢰 이상, 무전 호출·집결·해산) / 전장 아군(5~7막, 메인 퀘스트 배치, 지시 불가).
### 8.2 일시 동행 NPC (L1021~L1048)
- 모드: 추종(기본, 뒤 2~4t, 문 함께, 15t 넘게+시야 밖이면 뒤 3t로 텔레포트) / 엄호(교전 시 자동; 표적 순서 플레이어가 공격한 적 → 플레이어 공격 중인 적 → 가장 가까운 적; 사수는 엄폐, 돌격형 백구·큰돌은 붙음) / 은신 동조(함께 웅크림, 선제 사격 안 함, 소리 50%, 공격·발각 시 엄호; 백구는 3t 안 숨은 적을 짖지 않고 노려봄=위치 표시) / 대기(6t 안 적만) / 호위 대상(안 싸움, 엄폐로 숨음, 피격 시 도주; 예: 4막 S-07 주민 구출) / 지점 방어(반경 5t).
- 장비 퀘스트 데이터 고정(인벤토리 불가), 기본 무기 탄약 무한, 열화 없음.
- `HP = 기본 HP × (1 + 0.06×(플레이어 레벨 − 1))`. 카리스마 보정 `피해·DR × (1 + (카리스마 − 5)×0.02)` (SD-10 정본).
- 자기 회복: 전투마다 스팀팩 1회(HP 35%↓, 엄폐 뒤). 플레이어가 스팀팩 주기 없음. 동시 동행 상한 2명(대부분 1명).
- 사망·기절 플래그: 기절(기본; 쓰러져 표적에서 빠짐, 전투 후 HP 30%로 기상, 전투 중 2초 상호작용+스팀팩 1개로 HP 30% 기상, 원작 essential) / 사망 허용(사망 분기 있는 퀘스트만, SD-03a·03b·04, 결말 슬라이드는 퀘스트 결과로만) / 플레이어 고의 살해(기절 플래그여도 '기절' 처리 후 소속 세력 호감도 −20, 동행 종료; 이름 있는 NPC 살해는 퀘스트·대화로만).
- 전투 종료 시 HP 전량 회복. 동행 NPC 처치 XP는 플레이어가 30% 이상 피해 줬을 때만.
- **구현 정합(1-10a, §8.2 끝)**: `Companions.ROSTER` 하도윤(대걸레·근접 80) · 박춘삼(도끼·돌격 120) · 백구(물기 15·개 80), 그 밖 권총 사수 80. 추종 2~4t(둘이면 좌우) · 15t+안 보이면 뒤 3t · 엄호 표적 순서 · 사수 엄폐 칸 · 은신 동조(먼저 안 침, 백구 3t 노려보기 = 흰 역삼각) · 대기 6t(교전 중이거나 우릴 본 적만) · 호위 · 지점 5t. 기절 = HP 1 멈춤 → 눕고 표적에서 빠짐, 전투 끝 2초 → 30% 기상, 서 있던 동행 전량, 전투 중 2초 상호작용 + 스팀팩 → 30%, 자기 스팀팩 전투마다 1회(35%↓ → +35%). 주인공 폭발 아군 ×0.5(감시조 포함). 동행 처치 XP = 주인공 30%+. 말 걸기 '기다려/같이 가자/할 말이 있어'. 기다리는 동행은 그 맵에 남음(저장 포함). 고의 살해 판정은 아군을 칠 무기가 생길 때.

- 단계: 적대 −100~−60 / 경계 −59~−20 / 중립 −19~+19 / 우호 +20~+49 / 신뢰 +50~+79 / 동맹 +80~+100.

- 국지 적대 중 같은 세력 다른 분대는 '의심'으로 지켜보다 또 공격하면 합류.

- 행동 제한(넘어짐·붙잡힘·그물·기절·마비): 재적용 시 시간 갱신, 끝난 뒤 1.0s 같은 종류 면역.

- 적에게: 마비(패럴라이징 팜 10s), 넘어뜨리기, 광란, EMP 정지; 보스는 행동 제한 시간 절반.

## 11. 난이도·밸런스 (§10)
### 10.1 원칙 (L1317~L1322)

### 10.3 TTK (L1338~L1359; 표준 무기·스킬 50·보통, SD-14 §2.4와 같음)

### 10.4 레벨 스케일링 (L1361~L1395)

- `적 레벨 = clamp(장소 최소, 플레이어 레벨 + 장소 보정, 장소 최대)`, 장소 보정 −2~+3. 레벨 연동 목록은 플레이어 Lv 1·5·9·13·18·23·28에서 상위 변종·랭크 개방.

## 12. 상태·생존 (§11) — HP·방사능 두 축, 배고픔·갈증·수면 수치 없음 (D11-10)
### 11.1 HP (L1402~L1407)
- `최대 HP = 90 + 지구력×20 + 레벨×10` (지5·Lv1 = 200, Lv35 = 540). **자연 회복 없음**. 회복: 스팀팩 `30×(1+의학/50)`·음식·물·수면·의사(SD-15)·정착지 의료·퍽.
- HP 20%↓: 심장 박동음+화면 가장자리 붉은 맥동. HP 0: 사망 → 마지막 저장(SD-12). 부활·벌칙 없음.
- **생포 예외**: 계엄군 인도 분대·새벽인력 추심조·관제망 확보조(G3)의 비살상 공격으로 쓰러지면 생포 이벤트(SD-03a §6.7, N-47). 소지 캡 30% 압수(물 교환증·거처 보관함·조합 창고 제외). 하루 1회, 같은 날 또 쓰러지면 일반 사망.
### 11.2 방사능 (L1409~L1436)
- 누적, 자연 감소 없음, HP 직접 안 깎음.
| 라드 | 단계 | 효과 |
|---|---|---|
| 0~199 | 없음 | — |
| 200~399 | 경미 | 지구력 −1 |
| 400~599 | 심화 | 지 −2, 민 −1 (AP −2) |
| 600~799 | 위험 | 지 −3, 민 −2, 힘 −1 (AP −4, 소지 −10) |
| 800~999 | 치명적 | 지 −3, 민 −2, 힘 −2 (AP −4, 소지 −20) |
| 1,000 | 치사 | 사망 |
- 저항 `(지구력 − 1)×2%`, 상한 85%. 라드-X `25×(1+의학/50)`% 4분(비중첩·지속 연장). 라드어웨이 `50×(1+의학/50)` 제거(3s 대기열).

- 구역 등급(후보, 배치 SD-08·09): Z1 약 1/s(하천 웅덩이, 하저 터널 고인 물, 난지도 침출수, 용산 기지 오염 토양) / Z2 중 3(밤섬, 신월 빗물터널 침수, 도심 밀폐 구역 지상 일부; 라드-X 권장) / Z3 강 8(공릉동 연구용 원자로 내부, 당인리 지하 원전 침수 구간; 방호복) / Z4 매우 강 25(김포 방향 공항 폭심지 외곽 R10, 당인리 노심 근처) / Z5 치명 80+(공항 폭심지 중심, 당인리 노심 격실; **메인 필수 구간에 두지 않음**).

### 11.4 플레이어 부위 손상 (L1443~L1454) — 4부위

### 15.2 2안 비교 (L1680~L1697): A 트윈 스틱 vs B 탭 조준(정밀도·정체성·손가락 가림·학습·은신·근접·구현·대규모 교전 비교에서 A 우세, B는 학습 쉬움).
- **권장: A안 기본 + B 장점 2개**: ① 탭 사격(조준 스틱 0.2s 이내 탭 → 조준 보조 표적에 1발, 자동화기 점사 3발) ② 표적 고정(화면의 적 탭 → 고정 표적, 자석 조준이 우선). ③ B안 전체는 옵션 '간편 조작'(큰 사격 버튼, 표적 없으면 가장 가까운 적 자동 고정, 조준 보조 '강' 고정).
### 15.3 조준·사격 스틱 (L1699~L1709)
- 대기(손 뗌): 몸은 이동 방향 / 조준: 반경 25% 이상 끌어 유지, **터치 조준 = 정조준 취급**(퍼짐 ×0.5, 이동 3.0t/s, 리드 4t) / 사격: 바깥 링(반경 85% 이상) 밖에 있는 동안 사격, 링 안이면 조준만 / 탭 사격 0.2s 안: 보조 표적 1발(없으면 몸 방향) / 저격: 조준 0.6s 유지 → 스코프 안정·리드 6t, 링 밖 1발 / 데드존 0~25% / 떠다니는 스틱(기본)·고정 스틱(옵션), 영역 SD-12 §17.2 / 감도 1:1 절대 방향, '정밀 조준' 옵션 링 안 회전 ×0.6.
### 15.4 조준 보조 (L1711~L1727) — 키마는 보조 없음
| 항목 | 보통(기본) | 약 / 강 |
|---|---|---|
| 자석 원뿔 반각 | 15° | 10° / 22° (유효 사거리 ×1.0 안 적만) |
| 끌어당김 | 각도 차 60% | 35% / 85% (프레임마다) |
| 감속(마찰) | 충돌 원 위 회전 ×0.5 | ×0.7 / ×0.35 |
| 근접 보정 | ±30°, 0.5t 안이면 한두 걸음 다가감(달리기 프레임 거리 구동) | ±20° / ±40° |
| 투척 보정 | 착지 1t 안 적에 붙임 | 끔 / 1.5t |
- 보조 표적 우선: ① 고정 표적 ② 나를 공격 중 ③ 원뿔 안 가장 가까운 ④ 원뿔 안 HP 비율 최저. 아군·중립·제3세력 제외.
- 고정 해제: 사망, 시야 상실 1.5s, 화면 밖, 다른 적 탭, 빈 땅 탭. 적 직접 탭은 두 스틱 활성 영역 밖(화면 가운데·위)에서만. 탭 판정 반경 = 충돌 원 + 0.6t(약 19px).
- 집중 사격은 보조 표적에 자동 정렬(부위 가중 그대로). 은신 상태 끌어당김 절반.
- **보조는 조준 방향만 고침**; 퍼짐·명중·치명·부위는 §4 그대로. 옵션 끔/약/보통/강, 간편 조작 강 고정.
### 15.5 행동별 터치 (L1729~L1746)
- 이동: 왼쪽 떠다니는 스틱, 반경 25~85% 달리기 4.5t/s, 25% 안 걷기.
- 질주: 이동 스틱을 바깥 링 밖(질주 링)까지 0.3s 밀기 → 링 노랑; 떼거나 돌아오면 끝; 옵션 '질주 고정'.
- 집중 버튼: 탭 = 현재 조준 방향(조준 중 아니면 보조 표적)으로 집중 사격; 끌기 = 조준 스틱으로 바뀌고 놓으면 발사. 근접은 파워 공격(0.5s 차지). AP 부족 시 회색+AP 눈금.
- 구르기 버튼: 이동 스틱 방향, 입력 없으면 뒤로. 옵션: 스틱 두 번 튕기기.
- 재장전 버튼(탄약 수 표시), **모바일 자동 재장전 기본 켬**.
- 무기 아이콘 탭 = 직전 무기 교체, 길게 0.4s = 단축 휠 8칸(열린 동안 **시간 25%**, 반모달 SD-12 §2.1), 휠 가운데 = 무기 넣기.
- 투척 버튼 끌기 = 포물선 조준(끈 거리 = 거리, 최대 = 바깥 링), 버튼 쪽 되돌리면 취소; 탭 투척 옵션(기본 끔).
- 웅크리기 버튼 토글(은신 표시 SD-12 §4.5 버튼 위). 상황 버튼: 근접 장착 시 '막기'(누르는 동안), 대상 있으면 상호작용 우선(열기·말하기·줍기·해체), 3t 안 대상 직접 탭(전투 중엔 적 아닌 대상만).
- 회복 버튼 탭 = 스팀팩 1(대기열), 길게 = 소모품 목록, 0.4s 투여 모션 동일.

- 진동: 피격 약, 치명타 짧게 2회, 폭발 거리 비례, 탄 걸림 1회; 옵션 끔·약·강; iOS 햅틱.
