## 2. 핵심 원칙·금지 (L35~L44, §3.3)
- 주인공은 쫓지 않고 **쫓긴다**. 축: "200년 전의 명령을 누가 어떻게 끝내는가". 주인공=등록 관리자(열쇠).
- **월드는 MQ-P4 직후 전부 개방**. 막=이야기 단계(세계 상태 플래그 판정), 퀘스트는 장소가 아니라 목표.
- 경로 퀘스트: 막마다 2~5경로, 하나 끝내면 막 진행(XP 100%), 나머지 보너스(60%).
- **고르지 않고 기운다**: 진영 가입·동맹 확정·결말 선택 메뉴, "어느 편에 서겠습니까?"/"제안을 받아들이겠습니까?" 금지 문형(F6). 세력 대사는 부탁·의뢰·위협·초대, 응답은 행동. 선택지·화술은 개별 사안에만.
- 기울기 3겹: ①세력 호감도 10종(BJ·YH·WP·SB·JG·JH·GS·JC·NJ·KD) ②판도(거점 60·13구역) ③핵심 물건 인도처 HO 9종.
- 숫자 대신 세계 반응(호칭·가격·순찰·방송·깃발·지도). 숫자 표시는 설정 옵션.
- **동료 없음**. 일시 동행 NPC + 신뢰 이상 세력 지원 병력 호출로 대체.
- 메인 40개(프롤로그4+본편35+에필로그1; 막별 4/6/7/4/3/8/5/2/1). 1회차 필수 22개(에필로그 자동 제외). 필수도 실패 없음, 나쁘게라도 닫힘.

자유도 규칙 F1~F10(L306): F1 전부 개방(장벽=위협도·한강[다리·배·터널]·도심 밀폐[6막 진입로 4]) / F2 목표 문장, 지도 마커는 알려진 단서에만 / F3 먼저 이루면 '이미 알고 있음'으로 건너뜀, 나머지 보너스 / F4 막=세계 상태 조합 / F5 잠기지 않음, 모든 막에 '단독' 경로, 시간 제한은 나쁜 결과로 닫힘 / F6 진영 묻지 않음 / F7 물건·행동이 선택 / F8 세계가 먼저 말함(핍-보이 '세력 기록'은 한 줄 서술) / F9 양다리 허용(소문·방송·목격으로 연동 감소) / F10 무소속 가능: 신뢰 세력 없으면 3·5·6·7막 '단독' 판(난도↑, 보상 다름).
