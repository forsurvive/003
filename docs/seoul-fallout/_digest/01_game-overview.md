## 0. 한 장 요약 (L37~L49)
- 무엇: 실제 서울 무대 폴아웃 3 방식 오픈월드 RPG, 비상업 팬게임. 언제: **2277-10-23** 서울. 누구: S-07 등록번호 S07-2258-0031, 관제망 **등록 관리자**.
- 무엇을: 관제망 세 조건(전원·본부·관리자) 둘러싼 세력 사이 활동 → 광화문 지하 콘솔 앞 **행동으로** 결말.
- 보임: 쯔꾸르 스타일 3/4 탑다운 2D 도트(32px), 외부 심리스, 맵 위 실시간 전투, 장비 외형 반영.
- 플랫폼: PC(Windows 우선) + Android·iOS, Godot 4.x, 모바일 터치 트윈 스틱.
- 원작과 같은 것: 볼트 프롤로그, S.P.E.C.I.A.L.·스킬 13·퍽·카르마, 다중 해법, 스킬·화술 체크, 결말 슬라이드, 라디오.
- 다른 것: 줄거리 전체, 세력(브라더후드·엔클레이브 없음), 세력별 호감도·판도, 7막 다중 경로, **동료 없음**, **V.A.T.S. 1차 제외**, 음성 없음, 라디오 음악 없음.
- 규모: 메인 40·사이드 75·세력 69·비표시 124·반복 55·인카운터 157·장소 425·NPC 738(대화 735).
- 다음 할 일: 기술 시험판(Godot 4, PC·모바일 실측) → **버티컬 슬라이스(프롤로그 + MQ-101)**.

## 3. 하이 콘셉트 (L159~L221)
- 3.1: "폴아웃 3의 수도 황무지가 서울이었다면." 관제망은 **대전쟁 8분 전 '계엄 프로토콜 전면 집행'** 직후 전원 상실. 관리자 생체 인증으로만 명령. 기본값이면 볼트 밖 거의 전원이 적성 분자. 비상정부(이를 바람)·연합단(로봇 군대)·각성회(구원)·잔존병(본부 파괴 명령).
- 3.2 2분판: 16세 적성 평가 = 무조건 '관리 후보 1순위'. 2277-10-23 개방 지령 응답, 육지환이 2077 서류로 '등록 관리자 인도' 요구, 어머니 윤정인은 주민 전원 시민권과 자식을 교환하려 함. 탈출 넷(전투·은신·설득·하도윤). 결과는 남산 송신탑 '종전' 방송. 원작 '1950년대 미국이 상상한 원자력 미래' ↔ 서울판 '원자력과 진공관으로 2077년까지 달려온 한국'.
- 3.3 주제: "명령은 끝나지 않는다. 누군가 끝내기 전까지는." → **오프닝 자막과 맺음 슬라이드 ES-32에서 수미상관**.
