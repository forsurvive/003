## 4. 원칙 P1~P12 (L39~L98)
- P1 사실 = 변수 한 칸, 대사는 그 조건 뒤에서만. 경로가 여럿이면 같은 변수.
- P2 지식 장면 두 벌: '이미 앎' 판(주인공이 먼저 말하는 선택지 · 출처 반응 · 새 정보), XP 60%.
- P3 인물 = 상태 + 있는 곳 + 바꾼 사건. 세우기 전에 생사·위치. 이송은 사건(로그 한 줄).
- P4 큰 사건 = 서사 독점(`story_hold`): 다른 강제 사건 미룸 · 인카운터 금지 · 생포는 사건 훅만 · 저장·빠른 이동 금지.
- P5 '안전한 순간' 6조건: 자유 행동 · 교전 아님 · 생포/구속 아님 · 다른 독점 없음 · 요구 지형 · **다른 퀘스트 닫힌 무대 밖**. 미룬 사건은 조건 재검사 후 발동, 깨졌으면 대체 판.
- P6 시간 도약은 넘어간 06:00마다 하루 판정 + 돌아온 뒤 요약.
- P7 소문 = 사실 + 퍼짐(목격·방송·공개도). 전파 시스템 전엔 현장·당사자 세력만.
- P8 막 전환은 진행 중 퀘스트를 끊지 않음. 목표 문장 사실형. 순서: 사건 증감 → 예외 → 막 하한.
- P9 보상 사실마다 한 번 · 장면 재진입 가드.
- P10 저장은 정지 상태에서만. 긴 독점은 재개 단계로. 무대 이탈은 닫거나 따라옴 — '열린 채 떠남' 없음.
- P11 막히지 않음(대체 → 다른 경로 → 사유 남기고 닫음). 끝난 장소는 끝난 뒤 모습.
- P12 행적마다 반응 하나 이상, 알 수 있는 사람에게서만.

## 5. 충돌 우선순위 (L138~L155)
