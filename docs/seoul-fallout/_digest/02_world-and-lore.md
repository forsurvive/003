## 1·2. 요약과 정사 대조 (L16~L71)
- 요약: 1945까지 현실 → 정전 상태 분단, 미국 동맹 원자력·로봇 국가 → 2052 석유 단절, 원자력 전환 → **2063 북방 병합** → 2066 중미 전쟁 → 2074 전진기지 → 국가-재벌 '국가비상대비위원회' → **2075 비상계엄 + 분류 지침** → **2077-09 관제망 정식 가동** → 2077-10-23 **23:13** 섬광, **23:21** 계엄 프로토콜 전면 집행, **23:29** 고고도 핵폭발 EMP로 송전망 붕괴, 관제망 대기, 전기 시계 정지, **23:47** 마지막 탄두. 모든 피격 10-23 안.
- C1~C16 처리(L43~L58): C1 미 동부 09:13 = KST 23:13, 서울 피격 23:27~23:47, 24일 이후 새 탄두 없음 / C2 한국은 표적일 뿐 핵 미발사, 한국군 핵 없음(미군 관리 탄두만) / C3 '23:13 서해·북방 섬광 다수'만, 발사 주체 끝까지 미답 / C4 정사 사건은 배경 뉴스, 한국 사건은 그 뒤(2074 원정군, 2076 평택 T-51 정비창, 2077-01 탈환 축하) / C5 '청 주석의 중국'만, 중국 정보부가 침투조 운용 / C6 침투조 **헤이구이 스텔스 슈트**, 파워 아머 없음, 북방 병합지는 궁핍(소문) / C7 전자 산업 = **진공관·자기 드럼·테이프 릴**, 통신은 유선·공중전화·라디오·관공서 전자 공문, 학원 단말 녹색 단색 CRT / C8 한국은 면허 정비·부품만(태성중공업 평택), 계엄군 PA는 정비창 잔류 미군 프레임 200년 수리 / C9 S-01~S-12, 볼트-텍은 한결에 설계·장비 면허만, 발주처 한국 정부(한미 대피 협정) / C10 2052 유엔 해체로 유엔사 소멸, 정전 감시 한미 양자 / C11 소련은 기사 한두 줄, 러시아 연방 없음 / C12 미군 깃발 **원형 13별 + 가운데 별 1** / C13 1945-08-15까지 현실 / C14 체이스 장군·징웨이·리버티 프라임·브라운 박사 등은 서울에 안 옴(기사 제목만, '알래스카 해방!') / C15 지도 안 폭발 3발(김포·이촌·광화문 상공) + 우면산 1 + 요격 1, 위력 **350~550kt**, 도심은 폐허가 남은 상태 / C16 정부 2077-10-23 사실상 소멸, 비상정부는 자칭 정통, 2277 '국가' = 벙커 하나 + 계엄군 수백.
