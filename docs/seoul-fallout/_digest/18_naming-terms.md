## 2. 핵심 결정 N1~N15 (L25)
- N1 지명·공공 공간·지하철 노선/역명·정부 부처 일반명 = 실명. 인물·기업·브랜드·부대·무기 제식명·아파트 브랜드·언론사·학교·병원·종교 단체 = 가상.
- N2 중국 인명·부대 대호는 중국어 원음, 계급·직책은 한국 한자음(멍쉐밍 상위).
- N3 2277 지도 마커 = 황무지 통칭, 2077 공식 명칭은 진입 부제·표지판.
- N4 모델 번호 = 회사 접두 2자 + 분류 1자 + 연도 2자리. 화면은 애칭 먼저.
- N5 원작 퍽 RD-14 음차 유지, 신규 퍽 한국어 명사구.
- N6 인터넷·휴대전화·반도체 시대 어휘·초성체·밈 금지.
- N7 변수 뒤 조사는 `{변수|조사}` 토큰만. 숫자·로마자 끝 이름도 읽는 소리로.
- N8 데이터 키 = 국어 로마자 표기(음운 변화 반영) 소문자 스네이크 + 분류 접두. 외래어·원작 용어는 영문 철자.
- N9 RD-26 '불구(Crippled)' → **'부위 손상'**.
- N10 실존 유명인 동명 교체: 강태오→육지환, 천웨이→멍쉐밍(바이블 v0.4) + 세트 정합 14건(RECON_SPEC §2).
- N11 진영 선택 문구(가입·수락·'A 또는 B 선택')를 시스템·로그·퀘스트 제목에 쓰지 않는다. 목표는 사실·상태로(바이블 v0.4 §5.8).
- N12 호감도·판도는 숫자 대신 호칭·인사말·핍-보이 기록 한 줄·세계 반응. 숫자는 옵션.
- N13 '동료' 시스템 용어 금지. v0.2 동료 후보 7명 = 이름 있는 NPC.
- N14 이름 있는 NPC 500+ = 분포표·창립 가문 성씨·풀 P1~P12(+SD-07b §7.5)·D1~D8.
- N15 ID 체계는 §10 'ID 체계' 행이 세트 정본(RECON_SPEC §3).

등록 절차(L44): 바이블 §11/SD-18 §10에 있으면 그대로 → 없으면 §3~§7로 짓기 → 금지 목록(§2.3, §11) → 실존 인물·상표 동명 검사 → 데이터 키(§9.5) → 작성 문서 부록 '신규 고유명사' → 리드가 §10 통합. 이름 충돌 시 먼저 확정된 주관 문서 이름, 다른 것은 별칭(대사 전용).

## 4. 인명 (§3)
### 3.1 공통 (L170)
- 성 1자(복성 2자) + 이름 2자 기본. 외자 이름은 2277 황무지 출신에 많음.
- 김·이·박·최·정 ≤ 약 45%. 나머지는 긴 성씨 목록(복성 황보·남궁·제갈·선우·독고·사공·서문 포함).
