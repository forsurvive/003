## 2. 개요 (§1)
### 1.1 목적 (L12~L15): RD-17·RD-18을 탑다운 2D·심리스 외부·실시간 맵 전투·음성 없음(RD-27 P1·P3·P6·P7·P10)으로 재설계. 서울 고유: 관리자 코드·관제망 상태, 한강 횡단·빠른 이동, 주인공 현상금, 한국어 공문체 터미널, 한국어 단어 해킹, 조사 자동 처리.
### 1.2 요약 (L17~L28)
1. 핍-보이 3000: 원작 3탭, 능력치 탭에 **세력** 하위 탭 추가(3탭×5~6). S-07 지급품은 세진전자 면허 조립판 + **등록 단말 모듈**(관리자 코드 표시).
2. 세력 기록: 숫자 아닌 **관계 한 줄 서술+최근 사건**. 숫자는 옵션만. 변화는 세계 반응(호칭·바크·방송·가격·순찰)으로 먼저, 기본 설정은 숫자 토스트 없음(바이블 §5.8).
3. 퀘스트 기록: '막 목표+경로 퀘스트' 묶음. 목표 문구는 **상황과 사실**(예 `당인리 제어실 열쇠는 아직 당신 손에 있다`). 다른 경로·순서 파괴 달성 시 세계 상태 플래그 따라 갱신. **진영 가입·동맹·결말 고르는 UI 없음**.
4. HUD: 북쪽 고정 → 나침반 막대 대신 **원형 방위 링**. 지형 미니맵 없음.
5. 월드 지도: 장소 250+, 권역·유형·상태(발견·표시·소문) 필터, 지상·UG·HR·판도 레이어, SD-08 좌표 표시. 빠른 이동 = 지도+이동 목록(초성 검색·즐겨찾기). 강 건너는 빠른 이동은 **확보한 횡단로 ≥1**일 때만.
6. 대화: 텍스트+얼굴 96×96. 태그 `[화술 45%]`, `[과학 60]`, `[카르마]`, `[관리자 인증]`. **호감도 영향 미리 표시 안 함**. 주인공 말씨는 NPC 데이터가 정함.
7. 해킹 = **한국어 음절 단어 맞히기**, 위치 일치 `x/y`·괄호 짝 원작 그대로.
8. 범죄: 집단 단위 응징 + **수배도(주인공 현상금)** 변수, 비상정부·새벽인력 호감도 연동.
9. **결말은 관제 본부 콘솔 앞 오브젝트 상호작용**(생체 인증 판, 테이프 슬롯, 진공관 코어, 지휘 열쇠). **동료 시스템 없음**(K7) → 지원 병력 호출(신뢰 이상)+일시 동행 표시. 이름 있는 NPC 500+ → 이름표·서비스 아이콘·인물 수첩.

### 4.3 방위 링 (L542~L555)
- 지름 56px, 가장자리 4px 띠 `북`(8px) 고정, 중심 주인공.

## 10. 은신·범죄·현상금 (§9)
### 9.1 탐지 모델 (L1301~L1356)
- 관찰자마다 게이지 0~100.
- 시야 반경 `R = 4 + 인지력 × 0.6` 타일(인지 5 → 7t) × 조명(밝음 1.0 / 보통 0.8 / 어둠 0.55; 핍-보이 라이트 켜면 주변 '밝음').
- 시야각: 인간형 120°, 동물 150°, 로봇 기종 데이터(관제망 경비 로봇 90° 원뿔+3타일 360° 근접). 벽·높은 엄폐 차단, 낮은 엄폐(차량·화단·바리케이드)는 웅크린 주인공만.
- 시각 증가/초 = `60 × 거리 계수 × 동작 계수 × 은신 계수`; 거리 `1 − 0.75 × (거리 ÷ R)`; 동작 정지 0.4 / 웅크려 이동 0.7 / 걷기 1.0 / 달리기 1.5 / 사격 2.0; 은신 서 있음 1.0, 웅크림 `max(0.1, 1 − 은신 ÷ 120)`(60 → 0.5, 100 → 0.17); 은폐장(스텔스 보이 대응, SD-13) ×0.05(소리는 못 막음); 시야 밖 초당 −15; 소리 반경 안 관찰자 게이지 최소 40+조사; 웅크린 채 접촉 즉시 100; 시체 발견 최소 50+수색.
- 소음 반경(타일): 정지 0 / 웅크려 걷기 1 / 걷기 3 / 웅크려 달리기 4(사일런트 러닝 대응 1) / 달리기 7 / 문 여닫기·착지 2 / 무음 무기 0(못 죽이면 맞은 대상 [주의]) / 권총 14 / 소총·산탄 18 / 중화기 22 / 폭발 25 / 장착 무게 보정: 걷기·달리기 + ⌊장착 무게 ÷ 25⌋(사일런트 러닝 0).
- 상태: 모두 0~39 `[숨음]`(기습·소매치기) / 비적대 40+ `[발각]` / 적대 40~79 `[주의]`(기습 불가) / 적대 80~99 `[위험]` / 적대 100 `[위험]` 점멸=교전. '주의' 최소 8초 유지. 교전에서 표적 놓치면 80부터 감소.
- **충돌(중요)**: SD-11 §7.3 탐지 모델과 수치가 다름 — 시야 거리 `8 + 0.6×인지력`(SD-11) vs `4 + 0.6×인지력`(SD-12); 게이지 기준 초당 120(SD-11) vs 60; 거리 계수 `max(0.1, 1−(d/R)^1.5)` vs `1 − 0.75×(d/R)`; 은신 계수 `1 − 은신/150` vs `max(0.1, 1 − 은신/120)`; 스텔스 보이 0.1 vs 0.05; 시야 밖 감소 −10 vs −15; 상태 문턱 SD-11은 40 의심·100 발각(80 단계 없음); 소음 반경 SD-11 이동 2.0t·질주 5.0t·권총 12t·소총 16t·중화기 20t·폭발 18t vs SD-12 걷기 3·달리기 7·권총 14·소총 18·중화기 22·폭발 25; 동물 시야각 SD-11 개·곰 160° vs 150°. §1.4 경계표는 탐지 게이지 공식을 SD-12 소관이라 적음(L45), SD-11 §7.3도 자체 공식 보유.

- 대화: 대사 창 탭 = 다음(출력 중이면 완성), 선택지 행 40px+, **탭 = 강조, 다시 탭 = 결정**(옵션 '한 번 탭'), 위로 스와이프·`기록` = 대화 기록.
- 거래·컨테이너: 2단(각 300px), 끌어 놓기 또는 `옮기기`, 수량 슬라이더+`−`·`+`(40×40)·`전부`, `모두 가져가기`·`거래 확정` 큰 버튼(120×40), 거래 확정 2단계.
- 해킹: 1단×16행 스크롤(행 18px, 판정 36px), 탭 강조·다시 탭 입력, 기록창 오른쪽 고정, 한 화면 8행+스크롤 막대.
- 자물쇠: 원판 둘레 반원 호를 왼손으로 끌어 각도(밖을 짚어도 투영), 오른쪽 아래 `돌리기`(56×56) 누르는 동안 회전, 진동 피드백, `강제 개방`·`나가기` 위쪽.
- 터미널: 탭 실행, 끌어 스크롤, `이전`·`다음`. 레벨업·퍽: 탭 상세, `선택` 2단계. 대기·수면: 슬라이더+`−`·`+` 1시간. 엘리베이터: 40×40 격자, 101층 타워는 10층 단위 탭+스크롤.
- **결말 콘솔: 오브젝트 직접 탭, 2단계 확인 쓰지 않음, 길게 누르기 1.0초**(바이블 §5.8). 이름 짓기: OS 키보드, 화면을 위로 밀어 입력란 노출.
- 메모(불일치): 17.1(L1969)은 '결말 콘솔 행동'을 2단계 확인 대상에 넣었고, 17.5(L2068)는 2단계 확인 안 씀; 길게 누르기 시간도 7.9 '2~4초' vs 17.5 '1.0초'(M-20 미결).
