## 1. 이 세트의 목적

이 세트는 **'쯔꾸르(RPG Maker) 도트 그래픽 RPG 버전의 폴아웃 3'** 비상업 팬게임을 기획하기 위한 1단계 산출물이다. 원작 **폴아웃 3(2008, 베데스다 게임 스튜디오)**와 DLC 5종을 구성 요소별로 분해해 기록했다.

- **목표**: 팬게임이 원작과 최대한 같은 콘텐츠와 경험을 담을 수 있도록, 원작의 퀘스트·스토리·인물·세력·장소·시스템·데이터를 빠짐없이 정리한다.
- **전제**: 전투 시스템은 도트 RPG에 맞게 단순화할 예정이다. 그래서 전투 문서([RD-16](16_combat-system.md))에는 단순화를 결정하는 데 필요한 '전투 감성 요소' 분석을 따로 담았다.
- **각 문서의 구성**: 원작 분석(구조 → 규칙 → 데이터) → 설계 분석(의도, 강점과 약점) → **쯔꾸르 이식 메모**(보존 / 단순화 / 생략 후보) → 출처

## 4. 표기 규칙 요약

- 고유명사는 문서마다 처음 나올 때 `한국어(English)`로 쓰고, 그다음부터는 한국어만 쓴다. 기준은 [RD-26 용어집](26_glossary.md)이다.
- 데이터 표에는 항상 영문 원명을 함께 적는다. 팬게임의 최종 한국어 명칭은 본기획 단계에서 확정한다.
- DLC 태그: `[OA]` 오퍼레이션: 앵커리지 / `[TP]` 더 피트 / `[BS]` 브로큰 스틸 / `[PL]` 포인트 룩아웃 / `[MZ]` 마더십 제타
- `(코퍼스 미확인)`: 주 자료(아래 5절)에서 확인하지 못하고 일반 지식으로 보충한 내용이다. 본기획에 반영하기 전에 다시 확인해야 한다.

## 5. 자료 출처와 정확성 정책

- **주 자료**: Fallout Wiki(Nukapedia, fallout.fandom.com)의 공식 데이터베이스 덤프(2026-08-30판)에서 폴아웃 3와 DLC 관련 문서 11,149개를 추출했다. 퀘스트·인물·장소 문서, 데이터 표, 대사 원문 전사본, 터미널·홀로테이프 전사본, 공식 가이드 전사본이 여기에 포함된다.
- 수치(XP, 캡, 피해, DR, 요구 스킬 등)는 위 자료의 값을 그대로 옮기는 것을 원칙으로 했다. 플랫폼별 차이나 패치 차이는 필요한 곳에만 각주로 달았다.
- 각 문서 끝의 **출처** 부록에 참고한 위키 문서 제목을 적었다.
- 위키 콘텐츠는 CC BY-SA 라이선스로 배포된다. 이 세트는 그 내용을 한국어로 요약·재구성한 2차 저작물이다. 대사와 문서 원문은 분석에 필요한 최소한으로만 짧게 인용했다.

## 6. 권리 표기

Fallout, 폴아웃 3 및 관련 명칭·설정·캐릭터는 Bethesda Softworks LLC(ZeniMax Media)의 상표이자 저작물이다. 이 문서 세트는 비상업 팬 프로젝트의 내부 기획 자료다.
