# RD-13. 장소 카탈로그

> **폴아웃 3 역기획서 세트** | 문서 ID: RD-13 | 버전: v1.0 | 작성일: 2026-10-11
> **범위**: 지도 마커가 있는 모든 장소(본편 163곳 + DLC 61곳 = 224곳)의 카탈로그(유형, 지역, 위치, 개요, 출현 적, 주요 전리품, 관련 퀘스트, 실내 셀 수), 의미 있는 비표시 장소, 지하철·하수도 내부 구간, 장소 분포·보상 분석. 정착지·볼트의 구조·시설·주민 상세와 맵 구조(그리드·지하철망 규칙)는 다루지 않는다(RD-12). 퀘스트 진행은 퀘스트 문서, 적 능력치는 RD-24, 수집품 동선은 RD-23이 정본이다.
