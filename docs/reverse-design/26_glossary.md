## 1. 표기 원칙

1. **원어 병기**: 고유명사는 문서마다 처음 나올 때 `한국어(English)` 형태로 쓰고, 그다음부터는 한국어만 쓴다. 데이터 표에는 반드시 영문 원명 칼럼을 둔다.
2. **공식 한국어판 우선**: 폴아웃 3에는 공식 한국어판이 없다. 그래서 공식 한국어판이 있는 후속작(폴아웃 4/76)에서 굳어진 표기를 먼저 따르고, 확인되지 않는 것은 외래어 표기법에 따라 음차한다. 팬게임 안에서 쓸 최종 표기는 본기획 단계에서 다시 검토한다.
3. **번역과 음차의 구분**
   - 인명, 고유 지명, 상표, 팩션명, 퍽 이름은 **음차**한다. (예: 메가톤, 누카콜라, 블러디 메스)
   - 실존 랜드마크와 일반 명사형 장소는 **번역**한다. (예: 제퍼슨 기념관, 국립 문서 보관소, 기술 박물관)
   - 스킬, 일반 아이템, 시스템 용어는 **번역**한다. (예: 소형 화기, 사냥용 소총, 피해 저항)
   - 퀘스트 이름은 **번역**하고 원제를 병기한다. 말장난이 섞인 제목은 뜻을 살려 옮긴다.
4. **DLC 태그**: `[OA]` 오퍼레이션: 앵커리지 / `[TP]` 더 피트 / `[BS]` 브로큰 스틸 / `[PL]` 포인트 룩아웃 / `[MZ]` 마더십 제타
5. **수치 단위**: 캡(병뚜껑 화폐), XP(경험치), AP(행동력), HP(체력), DR(피해 저항 %), 라드(rad, 방사능 피폭량)
