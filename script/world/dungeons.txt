# 던전 표(단계 1-D0 · docs/seoul-fallout/_plans/1-D_dungeons_plan.md §1 · SD-14 §11.3 소굴 정리 · SD-09f §3.5 지하 공통 규칙).
# 1-B 생성 실내가 '들러 보는 곳'이면 던전은 '작정하고 들어가는 곳' — 깊이(층) · 우두머리 · 보상 · 한 번 정리하면 바뀌는 세계.
# 형식(한 던전 = '@ 접미 이름' 머리 + 줄 몇):
#   @ DB 대방 지하차도      → 던전 ID 'DG-DB' · 정리 변수 DG_DB(0 손 안 댐 · 1 정리 · 2 다시 들어섬) · DG_DB_DAY(정리 · 재입주 날)
#   lid 장소 L-ID           월드 장소(발견 · 지도 · 소문 출처)
#   map 맵ID 층 깊이        층 표시(HUD 장소 이름 옆) · 깊이 z(−3 이하 라디오 잡음 · −4 끊김, SD-09f §3.5). 맵 순서 = 입구에서 깊은 쪽.
#   music 곡ID              SD-17 던전 곡군
#   refill 일 확률 사람=적,… 짐승=적,…
#                           정리 뒤 '일'이 지나면 들어설 때마다(하루 한 번) '확률'%로 다시 들어선다 — 사람 먼저(70%), 아니면 짐승.
#                           자리 = 첫 맵의 우두머리 아닌 적 자리. 이름 있는 우두머리는 다시 서지 않는다(SD-14 §11.3).
#   clear 식                우두머리 말고도 정리로 치는 비전투 해법(이야기 식 — 참이 되면 정리)
#   chalk 상태 소품 "글"     월드 입구 곁 분필 표식(상태 0 손 안 댐 · 1 정리 · 2 다시 들어섬) — 없으면 표식을 그리지 않는다(초소 계단처럼 사람이 지키는 입구)
# 우두머리 = 맵 원고의 'enemy … boss=1' 줄(이 던전 맵들 안의 우두머리를 모두 쓰러뜨리면 정리).

@ DB 대방 지하차도
lid L-R02-17
map DB-01 지하 -1
music BGM-D06
refill 30 20 사람=CR-420,CR-423,CR-420 짐승=CR-121,CR-121
chalk 0 chalk_claw "분필로 그린 집게 — '물속에 뭐 있음. 엎드린 것도.'"
chalk 1 chalk_x "분필 가위표 — '가재 없음. 버스 옆 조심.'"
chalk 2 chalk_live "분필 사람 표시 — '누가 들어앉았음.'"
