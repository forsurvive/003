# 라디오 원고(단계 1-10b, SD-17 §4 · SD-12 §10) — 초안: Claude. 리드 검수 대기.
# 음악 없음(바이블 K11). 방송은 자막 띠의 글뿐이다: `[방송국] 화자: 문장`. 한 줄 28자 안(SD-17 §4.3).
# 머리 줄: '@블록 방송국 종류 ID | 조건'  — 종류: intro(인트로) · talk(진행 멘트) · info(생활 정보) · drama(연속극, ID 끝 숫자 = 회) ·
#   news(반응 뉴스: 조건이 처음 참이 되면 대기열에 들어가 다음 추첨에 먼저 나간다 — 사흘 동안 세 번) · outro(맺음) ·
#   speech(공보 연설) · slogan(오늘의 표어) · notice(공고: 조건이 참인 동안 순환) · chime(구내방송).
# 줄: '화자: 문장'. 화자 이름은 자막에 그대로 나온다. 끝에 [웃음] · [한숨] · [놀람] · [슬픔] · [긴급]을 붙이면 감정 스팅어(소리 단계).
# 원칙: 소식은 사실만, 기자 화법. 송미래는 MQ-205 전에는 주인공을 모른다 — '볼트에서 나온 사람' 수준의 소문만(SD-17 §4.4.7).
