# 생포 이벤트 — 새벽인력 판 (SD-03a §6.7 · SD-09a L-R02-19 H-03 '인력' 우리, 단계 1-3)
# 초안: Claude (SD-19 §9.3 단계 2). 리드 검수 대기.
# 진행(InteriorHost.capture): 생포 분대에게 쓰러짐 → 캡 30% 압수 → 근태 목걸이·수갑 → H-03 우리에서 깬다(CAPTURE_SB).
#   수갑·우리 문: [자물쇠 따기 25] 또는 [힘 7](SD-09a H-03 · SD-03a MQ-105 '일부러 잡힌다'). 목걸이: [수리 50] 또는 [과학 50](SD-03a §6.7).
#   사흘을 버티면 계엄군에 넘겨진다(1~3막 전원 없음 판: 청계산 귀빈실 → 남궁혁 면담 → 관악 산자락에 내려 준다, 비상 +5).
# 정합: 계엄군 판의 소지품 압수와 '압수품 보관함'(청계산 북사면 환기탑)은 청계산 맵이 생길 때 붙는다 — 지금은 압수하지 않는다.
#   마영식(300캡) 목걸이 해제는 지하시장(1-4)에서.

@npc   -
@cond  CAPTURE_BY == 1
