# 가산 아울렛 거리 DG-GA(SD-09a L-R01-28 · 1-D 계획 §12.5 · §12.6 · §12.7, 단계 1-D6). 초안: Claude. 리드 검수 대기.
# 진행기: Ga(@cmd ga …) — 사실은 변수 한 곳(P1):
#   GA_SEEN 망꾼을 봤다 · GA_BOX 작업복 상자(1 넘김 · 2 태움 · 3 바꿔치기 · 4 인솔조가 그냥 가져감 · 5 빈 상자) · GA_BOX_DAY 고른 날 · GA_BOX_DONE 판도 반영 ·
#   GA_CRATE_DAY 상자를 처음 본 날 · GA_FEUD 인솔조와 패거리가 틀어짐 · GA_DECOY 진열창 미끼(1 세움 · 0 없음) · GA_DECOY_DAY · GA_COUNTED 재고 세기에 걸린 수 ·
#   PD_R01_6 판도 PD-R01-6 사건 보정(+ 새벽인력 · − 약탈자) · DG_GA 정리(두목 N-GA-B1 — 던전 표).
# 동사: 눈을 속인다 — 방독면(A-074)을 쓰고 마네킹 줄 칸에 멈춰 서면 사람 눈엔 마네킹(쥐는 냄새로 안다). 볼트 작업복 차림이면 패거리가 사로잡으려 든다.
# 예상 밖 행동 목록(지침 2026-10-17): 계획 §12.7 1~22. 이 원고에 걸린 것만 다시 적는다:
#   · 상자를 안 건드리고 떠난다 → 처음 본 날부터 사흘 뒤 06:00 인솔조가 가져간다(GA_BOX 4 — 반쯤 된 상태 없음, P10). 새벽인력이 기울었으면 그대로.
#   · 인솔조가 하역장에 있을 때 태우기 → 선택지가 안 뜬다('보는 눈이 있다'). 바꿔치기는 상자를 열어 직접 — 인솔조가 있으면 그 자리에서 들킨다(진행기).
#   · 작업복만 다 빼 간다 → GA_BOX 5(빈 상자 — 패거리 탓). 우비를 넣고 빼면 바꿔치기(3).
#   · 미끼를 두 번 → 한 번만. 도로 벗기면 마네킹은 방독면 판으로(소문은 첫 미끼 다음 날 한 번).
#   · 볼트 작업복을 입은 채로 미끼를 세우려 한다 → 입고 있는 옷은 벗겨 입힐 수 없다(가진 다른 한 벌만).

# ================================================================ 진열창 — 미끼(엉뚱한 짓)
@scene GA_WINDOW  진열창  (L-R01-28)
@npc   -
@cond  V_ACT >= 1
? GA_DECOY == 1 -> DECOY
? DG_GA >= 1 -> FALLEN
SYS 진열창 유리 안쪽, 방독면을 쓴 마네킹 셋이 정문을 보고 섰다. 가운데 마네킹 목에 가격표 — '방호 우비 2+1 · 오늘만'.
? PD_R01_6 >= 10 -> TAG
? PD_R01_6 <= -10 -> TARGET
-> MENU
* TAG
SYS 셋 다 목에 번호표를 걸었다. 41 · 42 · 43. 누가 마네킹에게 인력 번호를 매겨 놓았다.
-> MENU
* TARGET
SYS 셋 다 가슴에 붉은 과녁이 그려졌다. 총알구멍 몇 개. 누가 여기서 사격 연습을 했다.
-> MENU
* FALLEN
SYS 진열창 마네킹이 모두 쓰러져 있다. 방독면 하나가 유리에 금을 그으며 굴러 멈췄다.
-> MENU
* DECOY
SYS 가운데 마네킹이 파란 볼트 작업복을 입고 섰다. 방독면 아래로 작업복 깃이 보인다. 멀리서 보면 — 사람 같다.
-> MENU
* MENU
> 가운데 마네킹에 볼트 작업복을 입힌다 -> DRESS ?? GA_DECOY == 0 and DG_GA == 0 and (has("A-001", 2) == 1 or (has("A-001") == 1 and worn() != "A-001"))
> 볼트 작업복을 입은 채로는 벗어 줄 옷이 없다 -> NOSPARE ?? GA_DECOY == 0 and DG_GA == 0 and worn() == "A-001" and has("A-001", 2) == 0
> 마네킹에서 작업복을 도로 벗긴다 -> UNDRESS ?? GA_DECOY == 1
> 그만둔다 -> END
* DRESS
SYS 마네킹 팔을 하나씩 비틀어 작업복 소매에 꿴다. 등 지퍼를 올리고, 방독면 끈을 깃 위로 고쳐 맨다.
SYS 유리 밖에서 보면 — S-07 작업복 차림의 사람이 진열창에 서서 정문을 지켜본다.
@cmd ga decoy
-> END
* NOSPARE
SYS 지금 입은 작업복을 벗어 입히면, 나는 무엇을 입나. 다른 한 벌이 있어야 한다.
-> END
* UNDRESS
SYS 작업복을 도로 벗겨 개킨다. 마네킹은 다시 방독면만 쓴 플라스틱이 된다.
@cmd ga undecoy
-> END

# ================================================================ 작업복 상자 — 잃는 선택(지하 물류 창고)

-> END

-> END
