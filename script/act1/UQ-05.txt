# ================================================================ 낙성대 고개 — 처진 누렁이(진행기가 UQ05_CX · CY에 세운다)
@scene UQ05_COW  낙성대 고개 — 누렁이  (L-R01-12)
@npc   N-UQ5-COW
@cond  UQ05_COW == 1
? UQ05_SAW == 0 -> FIRST
-> MENU
* FIRST
SYS 두 머리 누렁소가 짐을 진 채 풀을 뜯는다. 고삐가 중간에서 끊겼다. 짐 꼬리표 — '한강 행상 조합 · 연보경'.
? UQ05_CAUSE == 1 -> C1
? UQ05_CAUSE == 2 -> C2
SYS 고삐가 당겨 끊긴 자국. 소가 자꾸 귀를 턴다 — 큰 소리에 놀라 대열에서 달아난 소다.
-> SAW
* C1
SYS 끊긴 고삐 끝이 검게 그을렸다. 망루 쪽에서 쏜 총알이 고삐를 스친 자국.
-> SAW
* C2
SYS 소 뒷다리에 이빨 자국 셋. 들개 떼에 쫓겨 대열에서 떨어진 모양이다.
* SAW
! UQ05_SAW = 1; quest("UQ-05", 10)
* MENU
SYS 왼쪽 머리가 당신 냄새를 맡는다. 오른쪽 머리는 계속 풀을 뜯는다.
> 끊긴 고삐를 잡고 끈다 -> LEAD
> (지하 느타리를 내민다) -> FOOD1 ?? has("I-044") == 1
> (수경 상추를 내민다) -> FOOD2 ?? has("I-045") == 1
> 짐 꾸러미만 푼다 -> PACK ?? UQ05_PACK == 0
> 소를 잡는다 -> KILL
> 그냥 둔다 -> END
* LEAD
SYS 고삐를 두 번 감아 쥔다. 누렁이가 마지못해 따라온다 — 걸음이 느리다. 너무 멀어지면 서 버린다.
@cmd uqr cow_lead 1
-> END
* FOOD1
SYS 느타리 냄새에 두 머리가 동시에 고개를 든다. 고삐를 잡지 않아도 따라온다.
! take("I-044", 1)
@cmd uqr cow_lead 2
-> END
* FOOD2
SYS 상추 한 장에 두 머리가 다툰다. 고삐를 잡지 않아도 따라온다.
! take("I-045", 1)
@cmd uqr cow_lead 2
-> END
* PACK
SYS 짐 끈을 풀어 꾸러미를 내린다. 묵직하다 — 무두질한 가죽, 실타래, 정화통 몇 개. 꼬리표 '연보경'.
! give("M-429", 1); UQ05_PACK = 1; UQ05_PACK_DAY = GAME_DAY
-> MENU
* KILL
SYS 두 머리가 동시에 당신을 본다. 수송대 짐소다.
> 잡는다 -> KILL2
> 그만둔다 -> MENU
* KILL2
SYS 오래 걸린다. 두 머리가 차례로 고개를 떨군다. 고기를 발라 꾸러미로 싼다.
@cmd uqr cow_kill
-> END
