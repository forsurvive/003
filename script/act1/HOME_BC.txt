# 312번째 계단 옥탑방 — 봉천 거처(SD-15 §7.2 · §7.5 · §7.7 · SD-04a §2.5, 단계 1-8b)
# 초안: Claude (SD-19 §9.3 단계 2). 리드 검수 대기.
# 진행기: HomeBc(@cmd home …). MQ-101 완료 + 봉천 우호(AFF_JC_BC ≥ 20)가 찬 날을 HOME_BC_OK에 적고,
#   그다음 날 아침(06:00 하루 판정) 뒤 옥탑 이장실(B-01)에 들어오면 조만석이 옆방 문 앞에서 열쇠(M-136-BC)를 건넨다.
#   해법은 대사 한 줄만 바꾼다(SD-04a §2.5). 장면이 끝나면 방을 다시 들어와 거처 가구(보관함 2 · 진열장)가 선다.
# 압류(§7.7): 봉천이 경계로 떨어지면 '출입 자제' 쪽지(HOME_BC_NOTE) · 적대면 압류(HOME_BC 2, 보관함이 닫힌다 — 물건은 남는다) ·
#   중립으로 돌아오면 다시 연다. 백구(C-015)는 거처가 생긴 뒤 하루 판정마다 30%로 그날 옥탑방 문 앞에서 잔다.
